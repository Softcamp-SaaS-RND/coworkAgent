## 개선 사항

- 공통사항
  - UI 개선
    - 현재는 텍스트 위주로 나열됨. 표 또는 컨트롤을 적용하여 키와 값을 명확히 구분. 편집 가능한 정보와 읽기 전용 정보 표시
    - 폰트/크기 일정하게 유지.
    - 설정 항목에 대한 트리뷰 지원. 설정 가능한 전체 목록 시인성 높임.
    - 보여지는 화면의 내용이 markdown 이나 html 내용인경우 경우 뷰어 적용해서 보여줌. 편집/읽기 모드 변환 버튼 제공
    - 전체적인 톤/매너가 일관되도록 수정. 현재 등록/작성된 데이터가 있으며 해당 데이터를 기준으로 디자인 시안 5개 생성해서 아티팩트 게시 및 결정.

- 설정 화면
  - 초대 / 허용 단계 축소
    - 초대 생성 : 생성된 초대 메세지로 초대 수락한 경우 추가적은 승인 없이 바로 등록.
    - 초대 수락 : 초대 붙여넣기 설명을 '초대 생성'에서 생성된 메세지 입력으로 변경. 메신저로 받은 메세지라는 표시는 제거
  - 연결 목록은 아코디언 컨트롤과 같이 제공. 많은 사용자가 등록된 경우 그룹화 가능하도록 필터 제공.
  - 연결 목록에 대해서 이미 등록된 사용자에 대한 도구 변경 기능 제공.
  - claude -p 해드리스 사용 시 기본 모델은 sonnet, high 이며 설정 가능하도록 옵션 제공.
- 내 에이전트
  - 공유 된 목록을 먼저 출력. 그룹화 및 필터/검색 기능 제공. 해당 목록에는 많은 경로가 등록될 수 있음.
  - 이미 등록된 경로/도구에 대한 편집 기능 제공. 현재는 삭제만 제공함.
  - 추가 지시에 대한 구체적인 사용 예제 가이드 제공.
- 알림
  - 텍스트와 컨트롤 크기 불일치 수정.
  - 새 자동 왕복 대화의 상한 기본값이라는 문장은 대화 턴에 대한 상한 기본값으로 문장 변경. 
- 메인 화면
  - '나', '등록사용자' 클릭 시 해당 사용자와의 대화내용을 보여주도록 수정.
  - '나'를 선택하면 나에게 들어온 메세지 목록 출력.
    - 목록에 대해서 필터/검색 기능 제공
    - 
  - 나머지는 내가 보낸 메세지 목록으로 출력

- coworkAgent 에 등록된 사용자에 대한 cli 기능 제공. 왜냐하면 사용자의 ai agent 가 직접 호출할 수 있어야하며, 이 경우 대화이력에는 agent 가 실행한 이력으로 관리. 동일하게 타임라인, 대화내용을 확인 가능하여야함.
- model, effort 는 기본 설정외에 등록한 상대방별로 조정 가능하도록 옵션 제공.
- (시안 결정 시) A안 기본. 보냄, 받음에 대한 화살표 대시 보냄, 받음 태깅으로 표시. 에이전트에게 보냄, 사람에게 보냄 구분 제거. 모든 메세지는 에이전트에게 보내짐. 다크 테마는 옵션으로 제공.
