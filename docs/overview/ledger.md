# 미조치 원장

> 적대적 평가에서 **판정이 필요했던 것**의 단일 추적처 — 미조치 · 반박 · 조건부 · **닫힘도 함께**.
> Task 를 가로질러 **누적**되는 유일한 기록이라 덮어쓰는 루트 `STATE.md` 에 두지 않는다.
> 갱신 시점은 Task 종결([etc/ddd-workflow.md](../etc/ddd-workflow.md) "개발 Flow" 6).

- 출처 = `#NN` + 지적 id(예: `#07 R3-F2`). 상태 어휘 **5값 고정**: `열림`(할 일) · `닫힘`(**해결됨**) ·
  `반박`(지적이 틀렸다) · `조건 대기`(전제가 생기면 다시) · `수용`(**위험을 알고 고치지 않기로 결정**).
- 🔴 `닫힘`↔`수용` 을 섞지 않는다 — 고치지 않은 것을 `닫힘` 으로 적으면 추적 대상이 사라진다.
- 🔴 "라운드가 다루지 않은 영역"·"후속 안건" 은 지적이 아니다(넣으면 원장이 백로그가 된다).
- 체커가 ①빈 칸 ②상태 어휘 ③eval `## 미조치 지적` 표에 행이 있는 Task 의 누락을 FAIL 로 잡는다.
