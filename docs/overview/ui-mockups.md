> 데이터는 예시다. 선택 결과는 Phase 1 대화 UI Task 의 intent 로 옮긴다.

캔버스(비공개, 소유자만 열람): <https://claude.ai/artifact/Y6QUqV3NSqLC2wDEJLUb25>

| 시안 | 구조 · UX 축 | 강점 | 약점 |
| --- | --- | --- | --- |
| A 클래식 3단 메신저 | PC 레일 · 사이드바(내 에이전트 · 대화 · 연결 가능 사용자) · 대화 + 입력창 | 슬랙 사용자가 바로 익숙 · 의도 문서 "슬랙과 같은 디자인" 에 가장 가까움 | 에이전트 간 자동 왕복 흐름이 일반 채팅에 묻힘 |
| B 관제 콘솔 | 대화 카드 그리드(상태 · 왕복 n/10 막대) · 피어 · 이벤트 로그, 어두운 테마 | 여러 대화를 한눈에 감시 · 상한 · 오류 즉시 보임 | 대화 내용을 읽고 쓰기엔 한 단계 더 들어가야 함 |
| C 요청 인박스 + 작업 타임라인 | 받은/보낸 요청 목록 · 요청 → claude -p 실행(턴 · 시간 · 도구) → 응답 타임라인 · "이어서 작업" | D19(전체 이력 · 이어서 작업)에 가장 충실 · 감사 추적 쉬움 | 실시간 대화감은 약함 |
| D 에이전트 듀엣 | 두 에이전트가 좌우로 마주 보고 가운데 왕복 번호 · 사람 끼어들기는 가운데 띠 | D24 자동 왕복과 D18 사람 개입이 구조로 드러남 | 2자 대화 전용 — 다른 화면이 따로 필요 |
| E 단일 열 + 명령 팔레트 | 가운데 한 열 · 위쪽 피어 칩 · Ctrl K 팔레트(새 대화 · 이어서 · 피어 · 내 정보) | 키보드 중심 · 좁은 화면 · 최소 UI | 처음 쓰는 사람에게 기능이 숨겨짐 |
