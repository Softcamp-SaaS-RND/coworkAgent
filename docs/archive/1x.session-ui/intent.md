## 범위

- **세션 생성**: 모든 "새 대화" 라벨(상단 + 메뉴 · 화면 제목 · 사이드바 · 에이전트 줄 단추 · 도움말 · 매뉴얼 · README) → "세션 생성". 화면에서 메시지 · 메시지 종류 칸을 빼고
  "보내기" → "생성". 상대 칸 기본값 = 레일에서 고른 상대 타일(나 · 그룹이면 지금처럼 "상대 선택"). 생성 = 이 PC 에 글 없는 대화를 만들고 그 대화방으로 간다 — 첫 글(질의 · 요청)은 대화방
  입력창에서. 내 응답 에이전트 · 최대 응답 횟수 · 제목 · 그룹은 생성 때 대화에 붙는다.
- **입력창**: 요청 안내 문구(`#ask_hint`) 삭제.
- **대화 ⋯ 끝 항목**(내 대화 · 에이전트 대화) = **기록 삭제 ›** "내 글만 삭제" · "모든 사용자 글 삭제" + **나가기**(하위 메뉴 없음). 지금 "삭제" 는 없앤다.
  - **내 글만 삭제** = 대화방은 목록 · 그룹 · 즐겨찾기에 그대로, 이 PC 의 그 대화 글 전부(내 글 · 상대 글 · 에이전트 답) · 실행 · 에이전트 세션 기록 · 딸린 북마크 · 내 활동 · 요청 항목을
    지운다. 대화는 계속 쓸 수 있다. 상대 PC 사본은 그대로.
  - **모든 사용자 글 삭제** = 내 글만 삭제 + 상대 PC 도 그 대화의 글을 자동으로 비운다(새 프레임 · `Pong` 깃발 — 받는 쪽은 그 대화의 참여 상대가 보낸 것만 받는다). 양쪽 대화방은 남는다.
    그 대화의 관람자 사본도 비운다.
  - **나가기** = 확인 "대화방이 목록에서 삭제됩니다." → 나가며 이 PC 에서 글 · 대화방 삭제(지금 "삭제" — D40, 상대에게 "나감"). 읽기 전용으로 남기는 나가기는 없앤다.
- **상대가 나간 대화 · 1.0.x 에서 내가 나간 대화** ⋯ = 기록 삭제 › "내 글만 삭제" · "나가기"(목록에서 삭제).
- **관람자(공유 사본 · 해제된 사본 포함)** ⋯ = "나가기" 만 — 같은 확인 뒤 공유를 끝내고(D38) 사본을 목록에서 삭제. 기록 삭제 없음, 모든 내용 읽기 전용.
- **사이드바 대화 줄**: ☆ 단추 삭제, 손잡이(⠿) 포인터 끌기로 옮기기 · 그룹 타일에 넣기(지금 동작 그대로, HTML5 끌기 없음 · 줄 링크 `draggable="false"`). 즐겨찾기는 대화 머리 ☆ 로.
- **사이드바 머리**: '나' 부제에서 지문, 상대 부제에서 "페어링 됨" · 접속 문구를 뺀다(접속은 레일 점).
- **타일 크기 설정**: 설정 '화면' 에 "타일 크기" — 보통(지금) · 작게(아이콘 24px + 오른쪽에 이름 한 줄 말줄임, 레일이 그만큼 넓어짐). 이 PC 에 저장.
- **받은 요청 알림(B안 · OS 알림 보강)**: 받은 요청(`Ask`)의 브라우저 알림을 B안 모양에 맞춰 — 제목 "받은 요청 {대기 수}", 본문 = 최근 요청 줄(보낸 사람 · 제목 한 줄, 최대 3줄 + "외 n건"),
  같은 `tag` 로 앞 알림을 바꿔 쌓이지 않게, 누르면 요청 보드. 위치 · 모양은 OS 가 정한다(Windows 우하단 · macOS 우상단). 알림과 함께 짧은 효과음.
- **기본 테마 = 라이트**(저장된 값이 없을 때).
- **클립보드 이미지 붙여넣기 — 검토만**: 방식 · 한도 · 저장 위치 · 받는 쪽 에이전트 읽기 · 보안을 정리해 masterPlan 후보 줄로 남긴다(구현 없음).
