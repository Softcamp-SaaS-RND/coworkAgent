## 측정(디버그 빌드 1.4.2 `target\t17` · ego-browser 1440 × 900 · 1920 × 900 · 시험 데이터 = #1z-16 `ui1z16` 사본 `ui1z17`)

- **설정 화면**: 실행 · 화면 · 시작 · 알림 · 디버깅 — `.set-tiles` `grid-template-columns` = `900px`(1열) · 너비 900 · 타일 왼쪽 끝 하나(412), 1440 · 1920 같음 —
  이름 왼쪽 끝에서 컨트롤 오른쪽 끝까지 900. 디버깅 로그 상자 너비 989(창 너비 그대로). 화면 '날짜 표시방식' 옵션 넷(`md` · `relative` · `ymd` · `time`), 처음 값 `md`.
- **날짜 표시방식 넷**(select 로 바꿈 → `GET /api/settings` `ui_date_format` 저장 확인 → 대화 2):
  - md: 말풍선 메타 "10.23 10:51" · 요청 의견 "요청 의견 · 10.25 14:57" · 사이드바 "10.24 18:34" · 대화 정보 "10.23 10:50 시작 · 마지막 10.23 10:51".
  - relative: 같은 값(시험 데이터 글이 전부 그제 이전 — 오늘 · 어제 글자는 `view.test.mjs` format_time 이 고정).
  - ymd: "2026-10-23 10:51" · "요청 의견 · 2026-10-25 14:57" · 사이드바 "2026-10-24 18:34" · 대화 정보 "2026-10-23 10:50 시작 · 마지막 2026-10-23 10:51".
  - time: "10:51" · "요청 의견 · 14:57" · "18:34" · "10:50 시작 · 마지막 10:51". 다시 md 로 = md 값.
  - 다시 열기(reload): select `relative` 유지 · 시각도 그 방식.
  - 실행 상세 '진행' 시각: 시험 데이터에 실행 기록이 없어 화면 판독 못 함 — `runSteps` 시험(`view.test.mjs` run_steps)이 고정.
- **레일 상태 점**: 큰 타일 14 × 14 · 작은 타일 12 × 12, class `rail-dot offline` · 색 `--wait` · 위치 그대로.
- **에이전트 상세**(`coder`, `window.alert` · `window.confirm` 을 기록 함수로 바꿔 판독):
  저장 → alert "에이전트 coder을(를) 저장했습니다." · 상세 아래 "에이전트 저장 완료". 폴더를 없는 경로로 → alert "에이전트 coder 저장 실패: 폴더는 이 PC 에 있는 절대 경로여야 한다" ·
  상세 아래 같은 실패 글. 삭제 → confirm "에이전트 coder을(를) 삭제할까요?\n\n이어 쓰던 세션도 끊겨, …" → 취소 = `GET /api/agents` 에 그대로 남음.
- **좁은 시간 칸**(r03 — 사이드바 폭 272 · 창 1440 · 1000 · md · ymd · 목록 · 미리보기 · 두 테마): 사이드바 `.room-time` 줄 높이 22 그대로 · 넘침 없음, 개요 목록 시각 줄 21 · 넘침 없음,
  미리보기 `.pv-who` 잘림 없음 · 20. 대신 사이드바 대화 제목 칸이 줄어든다 — 시간 칸 md 67px · ymd 102px(예전 `HH:MM` 은 약 35px — 추정), 제목 보이는 폭 md 97 → ymd 62px
  (안 읽음 수가 있는 줄 74 → 39px). 제목은 원래도 "…" 로 잘리는 칸이라 깨짐은 아니지만 ymd 에서 제목이 짧게 보인다 — report 에 사용자 결정 항목으로 올림.
