# intent — 1l.ui-icons

작성: 2026-10-16 (착수 인터뷰 2 라운드 + 추가 지시 1건)

승인: 2026-10-16 (인터뷰 답 6건으로 범위 확정 — 아이콘 범위 · 말풍선 색 · 설정 정리)

## 왜

사이드바 메뉴 · 화면 제목 · 설정 항목 · ⋯ 메뉴가 글자뿐이라 한눈에 찾기 어렵다. 대화 말풍선은 내 글(#ECEDFD 연보라)과 상대 글(#F7F8FB)의 색이 거의 같아 좌 · 우
위치로만 구별된다. 설정은 안내문이 늘 펼쳐져 길고, 내 정보(읽기만 하는 표)가 설정 한가운데를 차지한다.
— 출처: masterPlan Phase 1 오버플로 `1l.ui-icons` · D35 · S4. 대화(2026-10-16) 사용자 원문: "사이드 네비의 매뉴명 앞에 매뉴 아이콘 추가. 대화창의 버블에 내
메세지와 상대방의 메세지 구분되도록 색상 적용. 내 활동 및 다른 매뉴에도 아이콘 없으면 아이콘 추가. 매뉴와 관련있는 아이콘을 매뉴명, 기능에 추가." · 인터뷰 답:
말풍선 "양쪽 다 색" · 내 글 "내 글 강조색 진하게 (Recommended)" · 범위 "화면 머리 제목 (Recommended), 설정 트리, 대화·타일 ⋯ 메뉴, 설정 매뉴의 매뉴 설명글들은
'?' 아이콘에 마우스 롤오버시 내용 출력하며 UI에서는 제거. 내 에이전트 매뉴의 '에이전트 등록' 왼쪽 레이블은 삭제. 내 에이전트 목록 위치는 연결 목록 하단으로 이동.
'내 정보'는 우상단의 사용자 아이콘 클릭 시 '사용자 정보' 매뉴 클릭 하면 팝업으로 제공하고 환경설정에서는 제거." · 지울 레이블 "검색칸은 제거, '새 에이전트
등록'은 '에이전트 등록'버튼 클릭 시 show/hide. '추가 지시등록 예'는 '에이전트 등록 > 추가지시' 매뉴 오른쪽에 '?' 에 롤오버 메세지로 이동." · 오른쪽 열 "한 열로". · 추가 원문(2026-10-16, plan 승인 전 추가): "환경설정에서 타일 매뉴의 순서 변경 제공. 사용자, 그룹 순이 기본이고 그룹, 사용자 순으로 변경 옵션 제공 추가. #new_btn 의 '자동왕복 대화' 매뉴는 제거. 버튼 클릭 시 매뉴에도 아이콘 추가 병행."

## 범위

- 아이콘 — 사이드바 메뉴(개요 · 내 활동 · 요청 · 주고받은 글 · 즐겨찾기 · 북마크 항목 · 에이전트) 이름 앞 · 각 화면 머리 제목 앞(같은 아이콘) · 설정 트리 항목 앞 ·
  대화 ⋯ 메뉴 · 타일 ⋯ 메뉴 항목 앞. 메뉴 뜻과 맞는 선 아이콘.
- 말풍선 — 내 글 = 강조색 바탕 · 강조색 위 글자(진하게), 상대 글 = 그 상대 타일 색(5색)을 연하게 깐 바탕 + 타일 색 띠. 다크 · 라이트 둘 다.
- 설정 — 카드 안내문을 화면에서 없애고 제목 옆 '?' 에 마우스를 올리면(키보드 초점 포함) 그 글이 뜬다. '내 정보' 카드 · 트리 항목 없앰 → 상단 바 프로필 메뉴
  "사용자 정보" → 팝업(같은 표). 한 열: 페어링 → 연결 목록 → 내 에이전트 → 실행 → 화면 → 시작 → 알림.
- 내 에이전트 — 검색칸 없앰 · "새 에이전트 등록" 접기 칸 대신 "에이전트 등록" 단추가 등록 칸을 보이기 · 숨기기 · "추가 지시 사용 예" 를 등록 칸 '추가 지시' 오른쪽
  '?' 롤오버로.
- 타일 순서 — 환경설정에서 레일 타일 순서를 고른다: 사용자(상대) → 그룹(기본) · 그룹 → 사용자. 이 PC 설정으로 남는다.
- "+ 새로 만들기"(`#new_btn`) 메뉴 — "자동 왕복 대화" 항목 없앰 · 남은 항목 앞 아이콘.
- README · 매뉴얼 · 캡처.

## 제외

- 프로토콜 · DB 스키마 변경(서버는 설정 열쇠 하나 — 타일 순서 — 만 더한다. 내 정보 API 그대로).
- 프로필 메뉴 항목 아이콘(인터뷰에서 고르지 않음).
- 자동 왕복 대화 기능 자체(새 대화 화면의 자동 왕복 칸은 그대로 — 메뉴 바로 가기만 없앰).
- 통계 메뉴.

## 결정

라운드 1(2026-10-16, 질문 2개): 말풍선 = 양쪽 다 색(상대 = 타일 색) · 아이콘 범위 = 화면 머리 제목 · 설정 트리 · 대화 · 타일 ⋯ 메뉴 + 설정 정리(답에 추가).

라운드 2(2026-10-16, 질문 3개): 지울 레이블 = 검색칸(+ 등록 칸 보이기 · 숨기기 · 추가 지시 사용 예 → '?') · 설정 = 한 열 · 내 글 = 강조색 진하게(권장안 — 상대 1번
색 #5B6CF0 이 강조색 #4E55D9 와 비슷해 연한 강조색이면 구별이 약함).

추가 지시(2026-10-16, plan 승인 전): 타일 순서 설정(사용자 → 그룹 기본 · 그룹 → 사용자) · "+ 새로 만들기" 의 "자동 왕복 대화" 없앰 · 그 메뉴 아이콘. "서버 변경 제외" 를 "설정 열쇠 하나만" 으로 좁혀 개정.

## 성공 기준

- A1: 사이드바 메뉴 · 화면 머리 제목 · 설정 트리 · 대화 ⋯ · 타일 ⋯ 메뉴 항목마다 이름 앞에 뜻에 맞는 아이콘이 있다.
- A2: 대화에서 내 글은 강조색 바탕, 상대 글은 그 상대 타일 색의 연한 바탕 + 띠라 색으로 구별된다(다크 · 라이트).
- A3: 설정 카드에 늘 보이는 안내문이 없고, 제목 옆 '?' 에 마우스를 올리거나 초점을 주면 그 안내가 뜬다.
- A4: 설정에 '내 정보' 카드 · 트리 항목이 없고, 프로필 메뉴 "사용자 정보" 가 같은 내용을 팝업으로 보인다.
- A5: 설정이 한 열(페어링 → 연결 목록 → 내 에이전트 → 실행 → 화면 → 시작 → 알림)이고, 내 에이전트에 검색칸이 없으며 "에이전트 등록" 이 등록 칸을 보이고 숨기고,
  "추가 지시" 옆 '?' 에 사용 예가 뜬다.
- A6: 루트 `PROJECT.md` 검증 명령이 모두 통과한다.
- A7: 환경설정에서 타일 순서를 "그룹 → 사용자" 로 고르면 레일에 그룹 타일이 상대 타일보다 먼저 오고(키보드 이동 순서도), 다시 열어도 유지된다. 기본은 사용자 → 그룹.
- A8: "+ 새로 만들기" 메뉴에 "자동 왕복 대화" 가 없고, 남은 항목마다 이름 앞에 아이콘이 있다.
