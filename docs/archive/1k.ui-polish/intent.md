'초대 수락' 칸으로 가 페어링 카드가 위에 오지 않는다. 설정 화면은 1j 디자인 캔버스 ④(두 열 · 카드 · 관리 단추)와 아직 다르다.

## 범위

- 에이전트 화면 — 안내문 "상대 에이전트를 누르면 새 대화, 내 에이전트를 누르면 설정으로" 없앰 · 내 에이전트 줄 오른쪽 연필(✎) 아이콘 → 설정 '내 에이전트' 의 그
  에이전트(펼친 채). 상대 에이전트는 아이콘 없음(누르면 지금처럼 새 대화).
- 주고받은 글 — 안내문 "주고받은 글 — 모든 대화, 최신순('나' 는 상대별), 누르면 그 대화로" 없앰 · 줄 왼쪽 상대 타일(레일과 같은 사람 모양 · 상대 색, 그림이 있으면
  그림) · 이름 옆 에이전트 칩(보낸 대화 = 상대 에이전트 이름, 받은 대화 = "내 {에이전트}").
- 대화 화면 — 말풍선 아래 "다시 보내기" 없앰(요청 상태 단추는 그대로).
- 레일 '+' — 설정 '연결' 을 누른 것처럼 페어링 카드가 맨 위에 오고, 초대 수락을 바로 할 수 있게.
- 설정 — 디자인 캔버스 ④: 두 열(왼쪽 페어링 · 연결 목록, 오른쪽 내 정보 · 내 에이전트), 페어링 카드 = 안내 + "초대 생성" · "초대 수락" 같은 모양 큰 단추 두 개,
  연결 목록 줄 = 끌기 손잡이 · 상대 타일 · 이름 · 부제 · "그룹 ▾" · "관리", 그룹 절 머리 = 그룹 타일 · 이름 · 수 · 이름 바꾸기 · 삭제 아이콘, 내 에이전트 줄 =
  타일 · 이름 · 폴더 · "관리", 머리에 "에이전트 등록".
