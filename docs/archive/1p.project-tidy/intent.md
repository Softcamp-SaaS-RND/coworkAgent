## 범위

- **문서**: 매 세션 필독을 루트 `CLAUDE.md` · `STATE.md` · `PROJECT.md` · ddd-workflow 핵심으로 줄이고, 나머지는 "필요할 때 여는 문서" 로 옮긴다
  (lazy-load) — ddd-workflow 의 문서 구조 계약 → doc-conventions, `PRODUCT.md` 의 흐름 · 화면 세부 → 개발자 가이드 · 새 web-ui.md. 같은 사실은 정본 한
  곳 + 나머지는 링크. 뼈대(`CLAUDE.md` · `docs/etc/`)를 고치면 `tools/check_ddd_docs.py` 를 같은 커밋에서.
- **코드 · 시험**: 동작 변경 없는 정리 — `notice_for` · `db_err` 중복 · `an-agent` 미사용 `serde` · `ux_literals.rs` 를 표로.
- **화면**: Nocturne 정본 강제 — `:root` 밖 리터럴을 토큰으로(글꼴 크기 · 굵기 · 줄높이 · 간격 · 둥글기 · 색), mono 범위, 입력창 안내 markup.
  재발을 시험이 막는다.
- **문구**: 메뉴 이름 · 제목 · 설명 · 빈 화면 · 툴팁 · 알림 문장을 문구 규칙(결정 6)으로 — 전 · 후 · 이유 표, 행별 승인.
- **동기화**: 사용자 가이드 · README · 매뉴얼 · 캡처.
- **추가**(결정 9): 로컬 빌드 캐시 · 빈 워크트리 폴더 삭제, `STATE.md` 낡은 항목 정리, 캡처 다시, UI 용어 표.
- (개정) **디자인**: Claude Design(claude.ai 디자인 캔버스 — Artifact Design 형)으로 AI 티 나는 시각 요소(흔한 남보라 강조색 · 여러 강조색 · 칩 남발 ·
  점선 상자 · 이모지 아이콘 · 숫자 아닌 곳의 mono 등)를 걷어낸 시안을 만들어 고르고, 고른 시안을 토큰 · 화면에 적용한다.
