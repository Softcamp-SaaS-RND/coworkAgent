  안 읽음 = 같은 유형 색 2px + 머리 "새 글 n".
- **사이드바 대화 목록의 내 대화 줄 유형 아이콘 지움**(결정 4): 사이드바 대화 목록(`#conv_sections`)에서 `out` 줄만 아이콘 없음. 에이전트 대화(로봇) · 공유 대화(눈) 줄과
  개요 · 검색 · 대화 머리 · 즐겨찾기 · 에이전트 응답 화면의 유형 아이콘은 그대로.
