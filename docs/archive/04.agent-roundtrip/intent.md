# intent — 04.agent-roundtrip

승인: 2026-10-11

## 왜
페어링까지는 되지만 아직 원격 에이전트에게 말을 걸 수 없다 — 제품의 핵심(S1)이 비어 있다. Phase 0 의 마지막 조각으로 사람 → 원격
에이전트 1왕복 · 이력 · 이어 쓰기를 세운다 — 출처: [masterPlan](../../masterPlan.md) S1 · S3 · S9 · D16 · D17 · D19 · D20 · D21 ·
D22(보강) · D24(개정) · SC1 · SC2 · SC3 · 확인 답(2026-10-11 "한도 없음(시간 제한만)" · "읽기 전용 (권장)") · 자동 진행 위임.

## 범위
- 에이전트 프로필(D21): 이름 · 작업 폴더 · 허용 도구(기본 Read · Grep · Glob) · 추가 지시문 — 웹UI 에서 등록 · 삭제
- 원격 에이전트 목록 조회(페어링된 상대의 프로필 이름)
- 사람 → 원격 에이전트 메시지 → 수신 PC 가 `claude -p` 실행(D16 · D22) → 답을 보낸 PC 로 돌려준다(D17 자동)
- 대화 · 메시지 이력을 양쪽 SQLite 에(D19 · SC3), 같은 대화에 이어 쓰면 `--resume` 으로 이전 맥락(D19)
- 원격 메시지(받은 요청 · 받은 답) 알림 — 03 의 브라우저 알림 + 트레이 경로(S9)
- 최소 웹UI(에이전트 · 대화 섹션) — 슬랙형은 Phase 1

## 제외
- 사람끼리 직접 대화 · 양쪽 발화(D18 · D23) · 자동 왕복(D24) — Phase 1
- 오프라인 상대 보관 후 재전송(D7) — Phase 2. 이번엔 전달 실패를 표시만
- 수동 확인(실제 `claude -p` 왕복 · PC 2대) — D28

## 성공 기준
- A1: 에이전트 프로필을 등록 · 조회 · 삭제할 수 있고, 새 프로필의 허용 도구 기본값은 Read · Grep · Glob 이다.
- A2: 페어링된 상대만 에이전트 목록 조회 · 메시지 · 답 전달을 할 수 있다(미페어링은 `not_paired`). 등록되지 않은 에이전트 이름은 거부된다.
- A3: `claude -p` 실행 인자는 D22 를 지킨다 — `--restricted --strict-mcp-config --permission-prompts none --permission-mode dontAsk`,
  프로필의 `--tools` · `--allowedTools`, `--output-format json`, 작업 폴더 = 프로필 폴더. 원격 텍스트는 인자가 아니라 표준 입력으로 넘긴다.
- A4: 사람이 보낸 메시지에 수신 PC 에이전트의 답이 돌아와 양쪽 이력에 남고, 같은 대화의 다음 메시지는 저장된 세션으로 `--resume` 한다.
- A5: 실행은 대화별로 직렬이고, 30분을 넘으면 종료되어 오류 답이 돌아간다. 수신 처리는 실행을 기다리지 않는다(바로 응답).
- A6: 받은 요청 · 받은 답이 알림(S9) 이벤트로 나간다.
- A7: 루트 `PROJECT.md` 검증 명령의 테스트 · 경고 0 · 의존 경계 행이 통과한다.

## 결정
- R1 새 크레이트 `an-agent`(domain) — 프로필 · 대화 · 실행기 · 왕복 조율. comm(`an-net`)은 페어링된 요청을 콜백으로 넘기기만 한다.
- R2 대화 ID 는 보내는 쪽이 만든 UUID 를 양쪽이 공유. 세션 ID 는 에이전트가 있는 쪽만 가진다(처음 실행은 `--session-id <새 UUID>`,
  이후 `--resume <ID>`).
- R3 전달은 비동기 두 단계 — 보내는 쪽 `message` → 받는 쪽 즉시 `ok`(대기열) → 실행 뒤 받는 쪽이 `reply` 로 되돌려 보냄(고정 키 연결).
  답 전달이 실패하면 받는 쪽 이력에 "미전달" 로 남긴다(재전송은 Phase 2).
- R4 메시지 본문 상한 16 KiB(프레임 64 KiB 안). 원격 텍스트는 저장 · 실행 입력 · 웹UI 에서 텍스트로만.
- R5 `claude` 경로: Windows `%USERPROFILE%\.local\bin\claude.exe`, macOS `~/.local/bin/claude`, 없으면 PATH 의 `claude`(전체 경로로
  실행 — PRODUCT 외부 전제).
- R6 권한 모드는 `dontAsk`(미리 허용한 도구 밖은 거부) + `--allowedTools` 를 `--tools` 와 같게 — 허용 도구는 묻지 않고, 그 밖은 없다.
