## 범위

- 사이드바 '에이전트' 하위 "에이전트 대화" → **"에이전트 응답"**(메뉴 · 화면 제목 · 빈 안내), '나' 타일에서만 보인다. 상대 타일은 '에이전트' › '등록된 에이전트' 만.
  상대 타일을 고를 때 에이전트 응답 화면이면 그 상대 개요로.
- 개요 아코디언('나' · 상대 타일): 절 머리 이름 앞 사용자 아이콘(그 상대 타일 모양 · 색), 대화 줄 에이전트 이름 앞 로봇 아이콘.
- 레일 "+" 두 단추 글자 "+ 사용자" · "+ 그룹".
- 대화 목록 줄 한 줄: 손잡이 · 로봇 아이콘(AI 에이전트 — 모든 줄 같은 아이콘) · 제목 · (실행 중 점) · (안 읽음 수) · 시각 · ⋯. 미리보기 · 발화자 아이콘 · 자동 왕복 · 태그 칩 없음.
- 레일 타일 끌기: 놓는 자리 = 포인터와 가장 가까운 같은 묶음 타일(틈 · 이름 · 양 끝 밖도), 레일 글자 선택 없음.
- 그룹설정 = 시안 B: 위 "그룹" 카드 격자(타일 · 이름 · 대화 수 · 대화 3개 · "+n 더 보기" / "대화 없음 — 끌어 놓으세요"), 카드를 누르면 카드 안에 대화 전체(그룹에서 빼기) ·
  카드 머리 이름 바꾸기 · 삭제. 아래 "사용자" 표(사용자 · PC · 상태 · 모델 · effort · 대화 · 관리), 줄을 누르면 아래로 펼쳐 관리(지문 · 주소 · 모델 · effort · 단추) + 그 사용자 대화 —
  대화 줄을 그룹 카드에 끌어 놓으면 넣기(복사). 검색 = 그룹 이름 · 사용자(이름 · PC · 지문) · 대화 제목.
- 주고받은 메시지 = 시안 `Peer`: 절 머리 그대로(타일 · 이름 · 건수 · 마지막 글 · 시각), 줄 = 원형 아바타(상대 사람 · 나 · 에이전트 색 구분) · 메타 한 줄(이름 · "사람" / 에이전트 이름 + "에이전트" 칩 ·
  대화 제목 · 요청 태그) · 본문 · 오른쪽 시각 · 북마크, 에이전트 줄은 옅은 에이전트 색 바탕.
- 매뉴얼 · README · masterPlan(D35 · D37 · S4) 반영.

## 성공 기준

- A1: '에이전트 응답' 메뉴(`#agents/convs`)가 '나' 타일에만 있고 상대 · 그룹 타일에는 없다, 화면 제목 · 빈 안내도 "에이전트 응답", 사용자에게 보이는 "에이전트 대화" 메뉴 이름 0건(node 시험 · 검사).
- A2: 상대 타일을 고를 때 에이전트 응답 화면이면 그 상대 개요로 바뀐다, 상대 타일 레일 배지는 그 타일에서 보이는 대화(에이전트 대화 제외)의 안 읽음만 센다(node 시험 · 검사).
- A3: 개요 아코디언 머리에 사용자 아이콘, 대화 줄에 로봇 아이콘이 붙는다(검사 · 실 화면).
- A4: 레일 "+" 단추 글자가 "+ 사용자" · "+ 그룹" 이고 보이는 글자가 접근 이름이다(검사).
- A5: 대화 목록 줄이 한 줄(2행 없음) — 손잡이 · 로봇 아이콘 · 제목 · 실행 중 점 · 안 읽음 수 · 시각 · ⋯, 미리보기 · 발화자 아이콘 · 칩 없음(검사).
- A6: 레일 타일을 같은 묶음 타일 사이 틈 · 이름 · 양 끝 밖에 놓아도 가장 가까운 자리로 옮겨진다(경계 = 타일 가운데)(node 시험 · 실 화면).
- A7: 그룹설정 = 그룹 카드 격자 + 사용자 표, 카드 누르면 펼침(대화 전체 · 그룹에서 빼기) · 이름 바꾸기 · 삭제, 사용자 줄 누르면 관리 + 대화 펼침, 펼침이 5초 새로 고침에도 유지(검사 · node 시험 · 실 화면).
- A8: 그룹설정 대화 줄을 포인터로 끌어 그룹 카드에 놓으면 그 그룹에 넣는다(복사, 대화 순서 안 바뀜), 설정 대화 줄에 HTML 끌어 놓기 없음(검사 · 실 화면).
- A9: 주고받은 메시지 줄 = 원형 아바타(상대 사람 · 나 · 에이전트 구분) · 메타(이름 · 사람 / 에이전트 칩 · 대화 제목) · 본문 · 시각 · 북마크, 에이전트 줄 바탕 구분(node 시험 · 검사 · 실 화면).
- A10: 회귀 없음 — PROJECT.md 검증 명령 PASS.

## 결정

1. '에이전트 응답' = 옛 '에이전트 대화' 메뉴(질문 답 "맞음"), '나' 에만 — D35 #1v(상대 타일에도 하위 둘) **개정**. 사용자 원문 "에이저트 응답" 은 오타로 보고 "에이전트 응답"(원문 첫 줄 글자 그대로).
2. 상대 타일에서 에이전트 응답 화면을 열 수 없으므로 상대 타일 배지에서 에이전트 대화 안 읽음을 뺀다(구현자 해석 — 보이지 않는 대화의 수를 타일에 남기지 않는다, '나' 의 '에이전트 응답' 메뉴 수가 그것을 센다).
3. 개요 아이콘 = 머리 사용자 · 줄 에이전트(질문 답).
4. 대화 줄 = 제목만(#1z A3 "미리보기 앞 발화자 아이콘" **개정**), 안 읽음 수 · 실행 중 점은 제목 줄로(질문 답), 아이콘 = 로봇 하나로 통일, 손잡이 그대로.
5. 레일 끌기 놓는 자리 = 가장 가까운 같은 묶음 타일 가운데 기준 앞 / 뒤(포인터가 레일 안일 때) — 원인은 놓는 점 아래 요소만 보던 것(코드 사실).
6. 그룹설정 = 시안 B(#1z 결정 11 "A 목록 + 상세" **개정**), 카드 관리 = 카드 눌러 펼침(질문 답).
7. 설정 대화 줄 끌기 = 포인터 끌기(다른 끌기와 같다 — HTML 끌어 놓기는 브라우저 끌기 확장이 가로챈다), 넣기만(놓는 곳이 대화 줄이어도 대화 순서는 바꾸지 않는다).
8. 주고받은 메시지 = 시안 `Peer` 줄 모양, 북마크 아이콘 유지(#1q).
9. 승인 절차: 이번 지시 · 질문 답을 intent 승인으로, plan 승인은 "위 작업까지 완료 후 병합, push 진행" 으로 갈음(#1z 결정 8 과 같은 방식).
