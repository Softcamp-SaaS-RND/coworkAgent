# intent — 1g.rail-scope

승인: 2026-10-14 (라운드 1 · 2 — 사용자 답 "Q1,2,3 의견도 반영하여 승인. 개발 진행")

## 왜

레일 타일('나' · 페어링된 상대)을 골라도 사이드바 메뉴가 거의 같고(대화 · 내 활동 · 요청 · 저장된 항목 · 에이전트 + 상대면 주고받은 글), '대화' 메뉴는
"목록에서 고르세요" 안내만 띄워 바로 아래 대화 목록과 겹치며, 사이드바 아래 '내 에이전트' · '{상대}의 에이전트' 절이 '에이전트' 메뉴와 겹친다. '나' 의
목록은 상대 구분 없이 한 줄로 섞여 상대별로 보기 어렵다. — 출처: 대화(2026-10-14) 사용자 원문 "레일 아이콘의 '나','{상대}'(페어링 된 사용자) 선택시
보여주는 메뉴가 중복되며 불필요한 매뉴가 식별됨 / 대화, 내 활동, 요청, 저장된 항목, 주고 받은 글, 에이전트 매뉴에 대해 '나'인 경우 요청은 모든
세션에서 수집된 내용을 그룹화 출력. / 레일아이콘의 추가된 사용자는 해당 페어링된 사용자 관련 내용만 보여주며 중복되는 '대화'매뉴, 내 활동 매뉴는
제거 / 즉, '나' 선택 시 모든 페어링된 사용자와의 내용을 그룹화하여 리포팅하여 출력하고 다른 레일의 사용자는 해당 사용자와의 대화나 요청, 저장된
항목, 주고 받은 글, 에이전트를 보여주도록 개선" · masterPlan S4(#17 보강 — 5영역 · 내 활동 · 저장된 항목) · D26(5영역 레일 · 사이드바).

## 범위

- '나' 메뉴 6개: 대화 · 내 활동 · 요청 · 저장된 항목 · 주고받은 글 · 에이전트 — 각 목록을 상대별 절로 묶는다.
- '나' 의 '대화' = 메인에 상대별 대화 요약. 사이드바 대화 목록도 상대별 절.
- 상대 타일 메뉴 4개: 요청 · 저장된 항목 · 주고받은 글 · 에이전트 — '대화' · '내 활동' 메뉴 제거. 사이드바 대화 목록은 그 상대 것만(지금 그대로).
- 상대 타일 첫 화면 = 그 상대 주고받은 글.
- 사이드바 '내 에이전트' · '{상대}의 에이전트' 절 제거.
- 상대별 절 접힘을 이 PC 에 기억(설정 `ui_folded` — 서버 변경은 이 설정 키 하나).
- '나' 의 '대화' 요약에 상대별 대기 요청 수.
- 그 밖은 웹UI 만 — 서버 목록 API 는 이미 상대 거르기(`peer`)가 선택이다. README · 매뉴얼 · masterPlan 반영.

## 제외

- 목록 API · DB 스키마 변경(설정 키 `ui_folded` 추가만).
- 레일 타일 순서 바꾸기 · 상대 그룹(여러 상대 묶음).
- 통합 검색 결과의 상대별 묶음.

## 성공 기준

- A1: '나' 를 고르면 사이드바 메뉴가 대화 · 내 활동 · 요청 · 저장된 항목 · 주고받은 글 · 에이전트 6개(이 순서)다.
- A2: 상대 타일을 고르면 메뉴가 요청 · 저장된 항목 · 주고받은 글 · 에이전트 4개(이 순서)이고 '대화' · '내 활동' 은 없다. 첫 화면은 그 상대 주고받은 글
  이고, 보이는 목록 · 화면은 그 상대 것만이다.
- A3: '나' 의 내 활동 · 요청(받은 · 보낸 탭 안) · 저장된 항목 · 주고받은 글 · 에이전트는 상대별 접이식 절(제목 = 상대 이름 · 건수, 레일 순서, 절 안
  최신순, 글 없는 상대는 숨김)로 나온다. 에이전트는 '내 에이전트' 절이 맨 앞. 접은 절은 다시 열어도(새로 고침 · 앱 다시 실행) 접혀 있다.
- A4: '나' 의 '대화' 는 메인에 상대별 요약(대화 수 · 안 읽음 · 대기 요청 수 · 최근 활동 시각 + 그 상대 대화 목록 — 누르면 그 대화)을, 사이드바 대화
  목록은 ★ 즐겨찾기 아래 상대별 절을 보인다.
- A5: 사이드바에 '내 에이전트' · '{상대}의 에이전트' 절이 없다.
- A6: 루트 `PROJECT.md` 검증 명령이 통과한다.
- A7: 상대 타일을 고른 채 내 활동 주소로 오면 '나' 로 바뀌어 열리고, '대화' 주소(`#`)로 오면 그 상대 주고받은 글이 열린다. '나' 내 활동에 '상대' 거르기
  칸이 없다.

## 결정

라운드 1(2026-10-14, AskUserQuestion — 네 질문 모두 권장안 선택):

- **Q1 '나' 메뉴 6개 · '대화' = 상대별 요약** — 사이드바 대화 목록도 상대별로 묶음. 기각안: '대화' 메뉴 제거(5개) · '대화' 는 지금 안내 화면.
- **Q2 상대별 접이식 절** — 제목 = 상대 이름 · 건수, 레일 순서, 절 안 최신순, 글 없는 상대 숨김. 기각안: 최근 활동 순 절 · 상대 탭.
- **Q3 상대 타일 첫 화면 = 주고받은 글** — 열린 대화가 그 상대 것이면 대화 유지. 기각안: 지금 안내 화면 · 요청.
- **Q4 사이드바 에이전트 절 제거** — 에이전트는 '에이전트' 메뉴 화면에서만. 기각안: 둘 다 유지 · 메뉴 제거.
