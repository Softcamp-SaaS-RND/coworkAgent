## 범위

- **타일 아이콘 색**(결정 1 ~ 6): 레일 타일 편집 폼(나 · 상대 · 그룹)에 '아이콘 색' 단추 — 에이전트와 같은 여섯 색(`ICON_COLORS`).
  상대 · 그룹은 처음 한 번 무작위 색을 정해 저장(있던 상대 · 그룹은 스키마 올릴 때), 편집에서 바꾼다. '나' 는 기본 흑연, 고르면 그 색(흑연으로 되돌리기 가능).
  색이 보이는 곳 = 레일 타일 + 그 사람 · 그룹의 머리글자 네모 전부(줄 타일 · 연결 · 그룹설정 · 검색 · 말풍선 · 요청 의견 · 주고받은 메시지 · 프로필). 그림이 있으면 그림.
  이 PC 에서만(표시 이름 · 그림과 같음).
- **그룹 그림 = 사람 + 그림자 둘**(결정 7): 앞 사람 가운데 + 뒤 좌우 옅은 사람 둘.
- **버전 1.4.0 그대로**(결정 8) — 스키마 28 → 29(결정 9).
- 개정 ② — **받은 대화 직접 쓰기**(결정 10 · 11): 받은 대화(내 에이전트가 답함)에 쓴 글은 내 에이전트를 실행하지 않고 양쪽 창에 사람 글로만(D23 개정),
  받은 쪽 사람 글은 자동 왕복을 멈추지 않는다(D24 개정 — 받은 쪽 멈춤은 머리글 "멈춤" 그대로). **머리글 '자동 왕복 거절 중' · 세부정보 '자동 왕복' 절 없앰**(결정 12).
  **세부정보 '요청' = 최근 3건 + 더보기 · 접기**(결정 13 · 14). 버전 그대로(결정 15).

## 성공 기준

- A1: 타일 편집에서 나 · 상대 · 그룹 색을 여섯 중 골라 저장 · 다시 열어도 그대로, '나' 는 흑연으로 되돌림.
- A2: 새 · 있던 상대 · 그룹은 여섯 중 한 색(저장 — 다시 열어도 같음).
- A3: 레일 · 머리글자 네모 전부에 그 색, 글자 대비 4.5:1 이상(두 테마).
- A4: 그룹 그림 = 세 사람(앞 가운데 + 뒤 좌우).
- A5: 기존 동작 · 문구 그대로(새 '아이콘 색' 문구만 더함), 검증 명령 PASS, 매뉴얼 · README 사진 반영, 버전 1.4.0.
- A6(개정 ②): 받은 대화에 쓴 글 = 실행 없음(`exec` false) · 상대 창에도 남음 · 받은 쪽 사람 글로 자동 왕복이 멈추지 않음.
- A7(개정 ②): 머리글에 '자동 왕복 거절 중' 없음 · 세부정보에 '자동 왕복' 절 없음 · '요청' 최근 3건 + "더보기" ↔ "접기" · 대화를 옮기면 다시 3건 ·
  받은 쪽이 멈춘 자동 왕복은 '대화 정보' 에 '자동 왕복' 줄.
