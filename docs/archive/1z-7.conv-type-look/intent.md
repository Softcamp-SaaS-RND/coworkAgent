## 왜

사용자 요청(seed `%APPDATA%\orca\floating-workspace\1021-cowork.md` "UI/UX 수정 (v1.3.3)", 2026-10-23) 원문:

- 대화창 제목(#conv_title)에 Agent, 사용자 아이콘을 추가.
  - 내 에이전트가 응답한 대화창과 내가 다른 에이전트와 대화한 대화창을 제목만으로 손쉽게 식별하기 위함.
- 설정-내 에이전트 의 편집
  - 저장, 삭제 옆에 닫기 버튼 제공. 닫기 클릭 시 펼쳐진 에이전트 편집화면 축소.
  - 이름, 폴더(절대 경로), 상위 한단계 탐색 허용, 셀 명령 실행 허용, 도구, 추가 지시 의 배치 정렬.
    - 아이콘은 사용자 아이콘이 아닌 Agent 아이콘으로 변경하고 색상 선택 가능하도록 제공.
    - 이름 편집은 가능한 경우 제공
- 대화창 유형에 따른 테두리 색 일관성 적용/유지.
  - 대화창은 내 에이전트가 대답, 내가 다른 에이전트에 문의 두가지 유형임.
    - 개요, 섹션의 리스트, 실제 대화창 등 대화창 표시 할 때 색상 일관성 유지.
      - 색상은 디자인 시안으로 3가지 제안 후 결정.

지금은 대화 유형(`dir` = `in` 내 에이전트가 답 · `out` 내가 문의)이 화면마다 다르게 보이거나 안 보인다 — 사이드바 대화 줄은 유형과 무관하게
전부 로봇 아이콘, 대화 제목에는 유형 표시가 없다. — 출처: 대화(seed), masterPlan S4 · D35, [#1z-2 report](../../archive/1z-2.ui-refine/report.md).

## 범위

- 대화 유형 표시를 세 가지로 맞춘다 — `in`(내 에이전트가 답) = 청록 `--agent` · 로봇 아이콘, `out`(내가 문의) = 파랑 `--accent` · 사람 아이콘, `shared`(공유 사본) = 회색 점선 · 아이콘 없음.
  닿는 곳(코드에서 센 대화 표시 전부 중 seed 의 "개요, 섹션의 리스트, 실제 대화창"):
  - 대화 화면 머리 — 제목(#conv_title) 앞 유형 아이콘(색 칠한 칩) + 머리 아래 2px 유형 색 선.
  - 사이드바 대화 줄 `convItem` — 대화 · 즐겨찾기 · 에이전트 응답 화면 모두(같은 함수): 줄 테두리 = 유형 색, 아이콘 칩 = 유형 아이콘 · 색, 고른 줄 = 유형 옅은 바탕.
  - 개요 미리보기 카드 `previewCardEl` — 카드 테두리 1.5px 유형 색, 머리에 유형 아이콘 칩, 안 읽음 = 바깥 윤곽선(테두리를 덮지 않게).
  - 개요 목록 보기 줄(`home_summary`) — 줄 왼쪽에 유형 아이콘 칩 + 유형 색 테두리.
- 설정 '내 에이전트' 상세: 이름(읽기 전용)을 폼 격자 안으로 · "아이콘 색" 6색 · 체크박스 옆 한 줄 설명 · 단추 저장 · 삭제 · 닫기(닫기 = 상세 접음).
  머리 아이콘 = 로봇 타일(고른 색). '등록된 에이전트' 화면의 내 에이전트 줄 점 → 같은 로봇 타일.
- 에이전트 색 저장 — 스키마 26 `agents.color`(토큰 열쇠, 기본 `agent-tile`), `PATCH /api/agents/{id}` `color`(목록 밖 400), `GET /api/agents` 응답에 `color`.
- 버전 1.3.3.

## 성공 기준

- A1: 대화 화면 머리 제목 앞에 `in` = 로봇 · `out` = 사람 아이콘(유형 색 칩), `shared` = 없음, 머리 아래 선 = 유형 색(시험 · 실제 화면).
- A2: 사이드바 대화 줄(대화 · 즐겨찾기 · 에이전트 응답) · 개요 미리보기 카드 · 개요 목록 줄의 테두리 색 · 아이콘이 A1 과 같은 유형 규칙 — `in` 청록 · `out` 파랑 · `shared` 회색 점선, 고른 줄 · 안 읽음 표시가 유형 테두리를 덮지 않는다(시험 · 실제 화면, 라이트 · 다크).
- A3: 설정 '내 에이전트' 상세 — 이름 · 아이콘 색 · 폴더 · 상위 탐색 · 셸 · 도구 · 추가 지시가 한 격자(값 열 한 줄 맞춤), 단추 저장 · 삭제 · 닫기, 닫기 = 상세 접힘 · 초점이 연필 단추로(실제 화면).
- A4: 아이콘 색 6개(`agent-tile` · `peer-1` ~ `peer-5`) 중 고르고 저장하면 다시 열어도 남고, 설정 머리 · '등록된 에이전트' 줄의 로봇 타일이 그 색 — 목록 밖 값 400, 색만 바꾸면 세대(`uid`) · 세션 그대로, 스키마 26(시험 · 실제 화면).
- A5: 회귀 없음 — PROJECT.md 검증 명령 PASS, 버전 1.3.3, 매뉴얼 · masterPlan 반영.
