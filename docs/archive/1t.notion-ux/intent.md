## 제외

- 브라우저 쪽 wasm SQLite · IndexedDB 트랜잭션 큐 — 가드레일 "이력은 사용자 경로 SQLite"(PROJECT.md) · 공통 원칙
  "설정은 단일 지점" 과 충돌. 서버 쪽 outbox(#1c)가 이미 같은 역할.
- 텍스트 CRDT — 대화는 램포트 시계(D23)로 충분, 공동 편집 문서가 아님. 분석도 병합 알고리즘 "확인 필요".
- Notion `/api/v3` 직접 호출 · 연동 — 분석 §8 WARNING(비공개 · 비보장).
- `meta_user_id` 다계정 캐시 PK · LRU 축출 · `boot:gate:*` 기능 플래그 — 한 PC 한 사용자, 해당 문제 없음.
- msgstore · Primus WebSocket 실시간 — LAN 두 PC, fan-out 문제 없음. 신호 방식만 B1 로 검토.
- 관찰되지 않은 편집 UX(슬래시 명령 · 블록 끌기 · 템플릿) — 근거 없음. 필요하면 로그인 세션 캡처를 먼저(분석 §9).
- 이 Task 에서 코드 변경 — 미해소 2 의 권장안대로면 구현은 항목별 후속 Task.
