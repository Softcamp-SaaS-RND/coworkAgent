## 왜

1r 에서 접이식 절의 하위 줄을 단계마다 들여 쓰면서 왼쪽 세로 안내선(`border-left`)을 함께 그었더니, 행 사이 가로 구분선과 만나 격자처럼 보인다.
README 는 1q · 1r 의 화면 변화(요청 개요 · 내 활동 범위 · 내 응답 에이전트 · 메뉴 초대 생성 · 새 에이전트 줄 · 연필)와 캡처를 아직 담지 않았다.
— 출처: masterPlan S4 · D35. 대화(2026-10-18) 사용자 지시 원문:

> 들여쓰기로 아코디언 컨트롤의 하위 매뉴 적용은 잘되었어. 그리드를 사용한것으로 보이는데 해당 그리드 라인은 제거해서 깔끔한 들여쓰기 모양으로 보이도록 UI 수정.
> (내 에이전트 목록, 내 활동, 요청 등 해당 매뉴의 아코디언 컨트롤 하위 매뉴 표시 할 때의 선 색상을 제거.)
> 위 작업까지 진행하고 readme 문서 업데이트까지 완료.

## 범위

- 접이식 하위 줄의 세로 안내선 제거(들여쓰기는 유지).
- README 기능 표 · 시작하기를 1q · 1r 화면에 맞추고, 캡처 5장(`workspace` · `pairing` · `agents` · `home` · `group`)을 다시 찍는다.
- web-ui 매뉴얼 · masterPlan D35 의 "안내선" 문구.

## 제외

- 행 가로 구분선(1r 전부터 있던 목록 구분선) · 새 대화 `.sub-label` 선(접이식 아님) — 그대로.
- 사용자 가이드 본문(1q · 1r 에서 이미 갱신) — 캡처만.

- A2: README 기능 표 · 시작하기가 요청 개요 · 내 활동 범위 · 내 응답 에이전트 · 최대 응답 횟수 · 메뉴 초대 생성 · 새 에이전트 줄 · 연필 편집을 설명하고, `check_readme` 가 통과한다.
- A3: README · 사용자 가이드 캡처 5장이 지금 화면(연필 · 새 에이전트 줄 · 들여쓰기)이다.
- A4: 기존 검증 명령이 green 이다.
