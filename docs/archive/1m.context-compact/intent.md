승인: 2026-10-16 (라운드 1 · 2 · 3 + 1M 추가 지시 — 사용자 "의견 수용. 개발 진행")

## 왜

한 대화를 오래 이어 쓰면 답하는 PC 의 Claude 세션(대화마다 하나 — D19)에 앞 대화가 계속 쌓인다. 실행마다 그 전부를 다시 읽어 답하는 쪽 구독 사용량을
낭비하고, 세션이 커지면 답이 느려진다. 지금 화면에는 세션 크기가 보이지 않고, 세션을 줄이거나 비울 방법도 없다.

sonnet는 1M 컨텍스트 지원함."

## 범위

- 컨텍스트 크기 — 답하는 PC 가 claude 실행 결과의 사용량(입력 + 캐시 토큰)을 답과 함께 보낸다. 대화 머리에 작게 "컨텍스트 42k / 1M" 으로 보인다(상한 1M 고정).
- 압축 — 상대(답하는 쪽) 에이전트가 지금까지 대화의 요약을 만들고, 그 요약을 첫 입력으로 새 세션을 시작한다. 요약은 대화에 글로 남는다.
- 비우기 — 그 대화의 AI 세션만 비운다(다음 글부터 새 세션). 화면의 대화 이력은 양쪽 그대로, 대화에 구분선.
- 단추 — 대화 머리의 컨텍스트 표시가 단추를 겸한다. 누르면 메뉴(압축 · 비우기), 확인 한 번. 묻는 쪽이 누르면 상대 PC 에 요청하고, 답하는 쪽은 바로 처리한다.
  실행 중이면 꺼진다.
- 대상 세션 — 그 대화의 세션 전부(대화 에이전트 + @멘션 에이전트). 압축은 에이전트마다 요약 1회. 크기 표시는 가장 큰 세션 기준.
- 경고 · 자동 압축 — 상한의 60% 넘으면 주황, 80% 넘으면 붉은색. 80% 를 넘으면 답하는 PC 가
  실행 직후 자동 압축(그 PC 설정 → 실행 "자동 압축", 기본 켜짐, 문턱 80% 고정) — 다음 글은 압축이 끝난 뒤 실행.
- 상대가 꺼져 있으면 압축 · 비우기 요청을 보내는 쪽 보관함(outbox — #1c)에 두었다가 켜지면 보낸다.
- 자동 왕복 대화 — 한쪽 세션이 자동 압축되면 다른 쪽 PC 세션도 자동 압축한다. 수동 압축 · 비우기도 두 PC 세션을 함께.
- 통신 형식 — 선택 필드만 더한다(0.4.0 상대와 주고받기 유지 — 그 상대의 크기는 "알 수 없음", 압축 · 비우기 요청은 거절 안내).
- README · 매뉴얼 · 캡처.

## 성공 기준

- A1: 답을 받으면 대화 머리에 그 대화의 컨텍스트 크기(토큰 / 1M)가 보이고, 크기를 모르면 "알 수 없음" 이다.
- A2: 머리 표시를 누르면 압축 · 비우기 메뉴가 열리고, 확인 뒤 실행된다. 실행 중에는 꺼져 있다.
- A3: 압축하면 답하는 PC 에서 요약이 만들어지고 다음 글은 그 요약으로 시작한 새 세션이 이어 받는다. 요약이 양쪽 대화에 보인다.
- A4: 비우면 다음 글은 새 세션(앞 대화 기억 없음)으로 실행되고, 대화 이력은 양쪽 그대로이며 구분선이 보인다.
- A5: 0.4.0 상대와 대화 · 주고받기가 그대로 되고, 그 상대에는 크기 "알 수 없음" · 압축 · 비우기는 안내와 함께 거절된다.
- A6: 80% 를 넘으면 자동 압축되고(설정으로 끔), 상한 60% · 80% 를 넘으면 표시 색이 바뀐다.
- A7: 상대가 꺼져 있을 때 누른 압축 · 비우기는 상대가 켜진 뒤 실행된다.
- A8: 자동 왕복 대화에서 한쪽 세션이 (자동 · 수동) 압축되거나 비워지면 다른 쪽 PC 세션도 같이 된다.
- A9: 검증 명령(`cargo test --workspace` · clippy · node 시험 · `check_gates` · `check_ddd_docs`) 통과.

## 결정

- 상한 = 1M 고정(60% = 600k 주황 · 80% = 800k 붉음 · 자동 압축) — 사용자 원문 "컨텍스트 크기는 1M 으로 측정. 왜냐하면 claude sonnet는 1M 컨텍스트
  지원함." 기각: 실행 결과의 모델 상한 값.
- 크기 출처 = 답하는 PC 의 실행 사용량을 답에 실어 보냄. 기각: 이 PC 글자 수 추정(도구가 읽은 파일 내용이 빠져 실제보다 훨씬 작다).
- 압축 = 요약 후 새 세션. 기각: `/compact`(헤드리스에서 되는지 확인 필요 · 남은 내용이 화면에 보이지 않음). 압축 1회는 답하는 쪽 구독 사용량을 쓴다.
- 비우기 = AI 세션만. 기각: 세션 + 양쪽 이력 삭제 · 세션 + 이 PC 이력만 삭제.
- 단추 = 머리 표시 겸 단추, 양쪽 누구나. 기각: 묻는 쪽만 · 대화 ⋯ 메뉴 안.
- 대상 = 그 대화 세션 전부(@멘션 포함). 기각: 대화 에이전트 세션만.
- 경고 = 색(60% 주황 · 80% 붉음) + 80% 자동 압축(설정으로 끔). 기각: 색만 · 경고 없음.
- 상대 꺼짐 = 보관했다 켜지면 보냄(outbox). 기각: 단추 끄고 안내.
- 자동 왕복 = 자동 압축 연동(한쪽 발동 → 다른 쪽도), 수동 압축 · 비우기도 양쪽 함께. 기각: 자동 왕복 제외 · 누른 쪽이 고른 세션만.
- 자동 압축 판정 = 답하는 PC 가 실행 직후, 설정은 그 PC(기본 켜짐 · 80% 고정). 기각: 문턱 고르기 · 묻는 PC 가 보내기 전 판정.
- 이전 버전(0.4.0) 상대 = 크기 "알 수 없음", 압축 · 비우기 요청은 상대가 거절하면 "상대가 0.5.0 이상이어야 합니다" 안내(꺼져 있어 버전을 모를 때는
  보관 → 켜진 뒤 거절되면 같은 안내). 기각: 단추 숨김.
