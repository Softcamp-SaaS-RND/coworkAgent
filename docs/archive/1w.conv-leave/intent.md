# intent — 1w.conv-leave

## 왜

사용자 요청(대화 2026-10-19): "모든 대화(초대 된 대화 포함)에는 상단 ... 매뉴에 `나가기`, `삭제` 매뉴 추가. `나가기` : 대화방 세션을 나감. 더이상 수신되지는 않지만
기존 대화이력은 유지. `삭제` : 대화방을 나감 + 대화세션 삭제 기능 추가 병행 작업."
— 출처: 대화, masterPlan **D40**(대화 나가기 · 삭제 — 착수 때 신설, 결정 5) · D38(공유 대화 — 관람자 "나가기"가 이미 있다) · D34(이력 정리 — 글 단위 삭제만, 대화 단위 없음).
이 Task 가 없으면 끝난 대화를 끝낼 방법이 없다 — 상대는 언제든 그 대화로 다시 요청을 보낼 수 있고, 대화를 지우는 기능이 없다.

추가 요건(사용자 2026-10-19 "1w 진행 승인. …1019-cowork.md 요건도 병행해서 작업", 이 Task 에 합침 — 결정 11) — 요건 원문:
"`환경설정` - `연결 목록` 기능 수정. 그룹 목록에 추가는 사용자 (PC)가 아니라 사용자와 대화한 대화목록이다. `그룹에 없는 연결`이 아닌 `사용자 목록` 이며,
사용자 목록의 사용자 선택 시 하위 트리에 대화목록이 출력됨. 해당 대화목록을 그룹에 Drag&Drop 로 복사. 복사하는 이유는 하나의 대화 세션은 여러 그룹에 포함될 수 있기 때문.
그룹 기능은 기존 사용자 별 대화 세션 중 필요한 대화세션만 선택하여 하나의 그룹으로 묶어주는 기능임." — 출처: masterPlan D37(그룹 = 대화 + 상대 — 개정 대상).

## 범위

- 모든 대화(내 대화 · 에이전트 대화 · 공유 대화)의 ⋯ 메뉴(줄 · 대화 머리)에 "나가기" · "삭제", 각각 확인 한 번.
- **나가기**: 이 PC 가 그 대화를 끝낸다 — 이력은 남고, 상대 PC 에 "나감" 을 알리고(새 프레임), 상대 쪽 그 대화는 읽기 전용(입력 막힘). 그 뒤 그 대화로 오는 요청은 거절 응답.
  공유 대화(사본)는 지금 `share_leave` 와 같은 동작.
- **삭제**: 나가기 + 이 PC 의 그 대화 · 글 · 실행 · 에이전트 세션 기록(`agent_sessions` · `conversations.session`) 삭제. 상대 PC 사본은 그대로.
- 나간 대화 = 목록 자리 그대로 "나감" 태그 · 읽기 전용(입력창 · 편집 없음 — 공유 해제됨과 같은 모양), 다시 들어가기 없음(새 대화로).
- 저장 스키마 21(나간 시각), `Pong` 깃발(이전 버전 상대에겐 프레임 대신 거절 응답만).
- **그룹 = 대화만**(D37 개정): 상대 단위 소속(`group_peers`) 폐지 — 스키마 이전 때 지금 상대 소속은 그 상대의 지금 대화를 하나씩 넣어 옮기고 지운다(한 번). 레일 상대 타일 메뉴 '그룹' 체크 ·
  설정 '그룹 ▾' · 상대 넣기 API 삭제.
- **설정 '연결 목록'**: 그룹 절 = 그 그룹 대화 줄(상대 · 제목) + "그룹에서 빼기", 끝 절 "그룹에 없는 연결" → **"사용자 목록"** = 지금 연결 관리 줄(타일 · 이름 · 관리)을 펼치면 아래에
  그 사용자와의 대화 트리. 대화 줄을 그룹 절에 끌어 놓으면 **복사**(원래 자리 그대로 — 사용자 목록 · 다른 그룹 모두에서).

## 성공 기준

- A1: 모든 대화 ⋯ 메뉴에 "나가기" · "삭제"(나간 대화는 "삭제" 만), 확인 뒤 실행(node 시험).
- A2: 나가기 뒤 이력은 그대로, 대화는 "나감" · 읽기 전용, 그 대화로 온 요청은 거절 응답(Rust 시험).
- A3: 상대 PC 는 "나감" 프레임을 받아 그 대화를 읽기 전용으로 표시, 이전 버전 상대는 보낼 때 거절 응답을 받는다(Rust 시험).
- A4: 삭제 뒤 이 PC 에 그 대화 · 글 · 실행 · 에이전트 세션 기록 · 딸린 항목이 없고 상대 PC 사본은 남는다, 같은 대화로 온 글은 거절되어 되살아나지 않는다, 지운 번호를 새 대화가 다시 받지 않는다(Rust 시험).
- A5: 공유 대화(사본) 나가기 = 지금 `share_leave` 와 같다, 삭제 = 나가기 + 사본 삭제(Rust 시험).
- A7: 그룹 소속은 대화만 — 상대 소속 API · 화면 없음, 이전 뒤 옛 상대 소속의 대화가 그룹에 남고 `group_peers` 행은 없다, 그 뒤 생긴 그 상대 대화는 자동으로 들어오지 않는다(Rust 시험).
- A8: 설정 연결 목록 = 그룹 절(대화 줄 · 빼기) + "사용자 목록"(관리 줄 + 대화 트리), 대화 줄을 그룹 절에 놓으면 복사 · 원래 자리 유지 · 이미 있으면 그대로(node 시험).
- A9: 도는 실행이 있으면 나가기 · 삭제가 막히고(안내), 아니면 대기열 글은 취소 · 자동 왕복은 꺼진 뒤 나간다(Rust 시험).
- A6: 회귀 없음 — PROJECT.md 검증 명령 PASS.
