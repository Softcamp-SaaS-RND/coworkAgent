# intent — 1f.message-edit

## 왜

대화 내용을 다른 곳에 옮겨 쓰기 번거롭고(복사가 마우스를 올려야 보이는 작업 막대 안 글자 단추), 끝난 대화의 이력을 사용자가 정리할 길이 없다
(메시지 편집 · 삭제 없음 — Task #17 A6 "메시지별 편집 · 삭제 · 원문 버튼은 없다"). — 출처: 대화(2026-10-14) 사용자 원문 "대화 말픙선에 '복사'를
의미하는 아이콘을 우상단에 배치.왜냐하면 대화내용을 손쉽게 복사해서 사용하기 위함. 대화내용 편집 모드는 프롬프트 상단에 배치 / 편집 모드 시
대화말풍선 선택 체크박스 발현. 다중선택 후 삭제 지원. 말풍선 내용 편집 지원. 말풍선 편집, 삭제는 상대방 창에도 동일하게 반영할지 내 창에만
반영할지 선택지 제공 / 이미 대화완료 된 내용을 수정, 삭제하더도 에이전트 처리는 다시 동작하지 않음. 해당 기능은 단순히 사용자의 자발적인 이력
정리의 의미로 제공" · masterPlan S3 · S4 · D19 · D23 · D26 · D32.

⚠️ **충돌** — masterPlan `## 의도` 비목표에 "메시지 수정/삭제 동기화" 가 있다(인터뷰 Q22). 이 요청의 "상대방 창에도 동일하게 반영" 은 그 비목표를
뒤집는다 → masterPlan 개정(사용자 승인) 뒤 인용한다(라운드 1 Q1).

## 범위

- 말풍선 우상단 복사 아이콘(본문 markdown 원문을 클립보드로) — 늘 보인다.
- 입력창(프롬프트) 위 "편집" 단추로 편집 모드 — 켜면 **내 사람 글**마다 선택 체크박스 · 연필(내용 편집), 여러 개 골라 삭제. 지금 열린 대화만.
- 편집 · 삭제 때 반영 범위 선택: 내 창에서만 · 상대 창에도(새 피어 프레임 + 1c outbox 다시 보내기).
- "(편집됨)" 표시.
- 편집 · 삭제는 에이전트 실행을 다시 일으키지 않는다(이력 정리 전용).
- 매뉴얼 · PRODUCT · masterPlan 반영(비목표 개정 · D34).

## 제외

- 에이전트 답 · 상대가 쓴 글의 편집 · 삭제(라운드 1 사용자 답 "수정, 삭제는 사용자 이력에만 적용").
- 편집 · 삭제로 인한 에이전트 재실행 · 다시 보내기(사용자 원문 "에이전트 처리는 다시 동작하지 않음").
- 에이전트 기억 바꾸기 — "이어서 작업" 의 Claude 세션(`--resume`)은 고치기 전 원문을 기억한다. 매뉴얼에 안내만.
- 고치기 전 원문 보관 · "삭제된 메시지" 자리 표시.
- "보낸 메시지" 탭 · 저장된 항목 · 검색 결과에서의 편집.
- 대화 통째 삭제.

## 성공 기준

- A1: 모든 말풍선 우상단에 늘 보이는 복사 아이콘이 있고, 누르면 본문 markdown 원문이 클립보드에 들어가며 "복사했다" 가 잠깐 보인다. 작업 막대의
  "복사" 글자 단추는 없다.
- A2: 입력창 위 "편집" 단추로 편집 모드를 켜고 끈다. 켜면 입력창 자리가 "n개 선택 · 삭제 · 완료" 막대가 되고(보내기 없음) 지금 열린 대화에만 적용된다.
- A3: 체크박스 · 연필은 내가 쓴 사람 글(웹UI · CLI) 중 끝난 글에만 보인다 — 에이전트 답 · 상대 글 · 보내는 중 · 실행 대기 · 실행 중 글에는 없고,
  API 로 직접 요청해도 거절한다.
- A4: 여러 글을 골라 "내 창에서만" 삭제하면 이 PC 에서 완전히 사라진다(대화 · 저장된 항목 · 검색 · 보낸 메시지 · 요청 목록 · 내 활동). 그 요청의 답은
  남고 상대 창은 그대로다.
- A5: "상대 창에도" 삭제 · 편집이면 상대 PC 에서도 같은 글이 지워지거나 같은 본문 + "(편집됨)" 이 된다(상대 요청 목록 포함). 상대가 꺼져 있으면
  outbox 로 다시 보내 켜질 때 반영하고, 24시간 안에 못 하면 그 대화에 "상대 반영 실패" 를 알린다.
- A6: 내용을 편집해 저장하면 본문이 바뀌고 "(편집됨)" 이 보인다. 순서(lc) · 요청 상태는 그대로다.
- A7: 편집 · 삭제는 양쪽 어디에서도 에이전트 실행 · 다시 보내기 · 자동 왕복 · 알림을 일으키지 않는다.
- A8: 상대에게서 받은 편집 · 삭제는 **그 상대가 쓴 사람 글**일 때만 적용한다 — 내 글 · 에이전트 답 · 다른 상대의 대화를 겨냥하면 거절한다.
- A9: 루트 `PROJECT.md` 검증 명령이 통과한다.
