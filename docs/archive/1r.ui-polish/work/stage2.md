## 실화면 확인(mock — `docs/archive/1q.request-overview/design/mock.py crates/app/web 8941`, Edge headless 1440×900)

- 새 대화: "안 함" → 최대 응답 횟수 줄 숨김, 에이전트 고름 → 한 단 들인 줄 + 안내선 · 라벨 7개 아이콘(다크 · 라이트).
- 요청 개요: 받은 요청 → 상대 절(한 단) → 행(두 단) · 안내선 · 탭 ↓ 받은 요청 · ↑ 보낸 요청. 주고받은 메시지 · 개요 상대 절 → 행 한 단.
- 알림 '?' 초점 → 위로 열린 설명 4줄(다크 · 라이트).
- 동작 점검 스크립트(`check1r.mjs`) 출력:
  - `#settings/invite_accept` → 수락 칸 펼침 / `#settings/agents` → 접힘 / 레일 + → 펼침 / `#new` → 접힘.
  - `#settings/invite_make` 해시로 옴 → 초대 상자 없음 / 트리 "초대 생성" 클릭 → 초대 상자 보임 / 새로 만들기 "초대 생성" → 초대 상자 보임.
  - `#new` 처음 → 최대 응답 횟수 숨김. JS 오류 0.
- 내 에이전트: 연필 → 상세 펼침 · 단추 강조, "에이전트 등록" → 목록 끝 "새 에이전트" 줄(+ 타일 · 이름 초점 · 취소 · 등록).
- 프로필 메뉴: 사용자 정보 · 프로필 편집 · 알림 일시 중지 · 설정 아이콘, 상태 셋은 색 점.
