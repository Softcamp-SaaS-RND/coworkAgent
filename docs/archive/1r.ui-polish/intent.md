## 왜

새 대화의 "자동 왕복" · "자동 왕복 상한" 이 무슨 뜻인지 모호하고, 접이식 목록(개요 · 요청 · 주고받은 메시지)은 펼친 하위 줄이 상위와 같은 들여쓰기라
부모 · 자식이 구분되지 않는다. 설정은 '연결 → 초대 생성' 메뉴가 초대를 만들지 않고, '초대 수락' 칸이 한 번 열리면 닫히지 않으며, 에이전트 등록 칸 ·
"관리" 단추가 다른 편집 동작(연필)과 모양이 다르다.
— 출처: masterPlan S4(웹UI) · D35(사이드바 메뉴). 대화(2026-10-18) 사용자 지시 원문:

> '새 대화' 생성 페이지의 '자동 왕복', '자동 왕복 상한' 용어가 모호함. 해당 용어를 '내 응답 에이전트'로 설정하고 자동 왕복 상한 값은 10으로 유지하지만
> 컨트롤은 '내 응답 에이전트'의 서브 매뉴로 제공. 각 매뉴에 대한 아이콘 추가.
> 아코디언 컨트롤이 적용된 경우 하위에 펼쳐진 매뉴가 상위 매뉴보다 하위 매뉴임을 알 수 있도록 탭정렬. 부모 <tab>하위 <tab>하위 위와 같이 서브 항목임을
> 직관적으로 알 수 있도록 정렬. '개요', '요청', '주고받은 메세지'의 항목에 적용.
> '환경설정'의 '자동왕복' 옆에 ? 아이콘 추가. 자동왕복이 어떤 기능을 의미하는지와 드롭다운의 항목들에 대한 설명을 마우스 오버시 표시.
> '연결'-'초대 생성' 매뉴 클릭 시 초대 생성 버튼 눌림 상태아님 오류 수정. '연결'-'초대 수락' 매뉴가 항상 펼쳐짐 상태 오류 수정.
> '에이전트 등록'버튼 클릭 시 등록되어 있는 에이전트 구분선 아래에 등록 컨트롤 추가. 새로 등록되는 모양으로 제공.
> '에이전트'의 '관리'버튼을 연필 아이콘으로 변경. 변경, 수정 관련 매뉴는 연필 아이콘으로 통일하여 look&feel 유지.

코드 사실(2026-10-18 조사):

- **새 대화**(`index.html` `#new` `#chat_form`) — 줄: 상대 `chat_peer` · 상대 에이전트 `chat_agent` · **"자동 왕복"** `chat_relay_agent`(옵션 "안 함" + 내 에이전트)
  · **"자동 왕복 상한"** `chat_relay_cap`(number 1 ~ 50, 값 10) · 제목 · 메시지 · 메시지 종류(질의 · 요청) · 보내기. 라벨에 아이콘 없음. 상한 칸은 "안 함" 이어도 보인다.
- **"자동 왕복" 이 쓰이는 다른 곳** — 설정 알림 `notify_relay` 라벨 "자동 왕복"(옵션 `start_end` "시작과 끝" · `every` "메시지마다" · `off` "알리지 않음"),
  `relay_cap_default` "자동 왕복 기본 상한", 세부정보 `#detail_relay_sec` 절 "자동 왕복", 대화 상태 "자동 왕복 받는 중" · "자동 왕복 거절 중", 사용자 매뉴얼 10장 제목.
  알림 의미(`crates/app/src/notify.rs`): `start_end` = 왕복 시작 · 끝(`RelayStart` · `RelayEnd`)만, `every` = 그에 더해 오가는 글마다(`RelayStep`), `off` = 없음.
  자동 왕복 = 상대 에이전트의 답 → 내 에이전트 → 상대 에이전트 … 를 상한까지 자동으로 주고받는 것(매뉴얼 10장).
- **아이콘** — `app.css` `.ico-*` 마스크 아이콘 28종(arrow-down · arrow-up · bell · bookmark · bot · chat · check · compress · enter · gauge · home · image-off · inbox ·
  link · minus · monitor · more · panel · pencil · play · plus · power · reset · star · swap · trash · user · users · x).
- **접이식 목록** — `app.js` `foldEl(key, head, body, cls, headCls, shut)` = `<details>`.
  개요(`#home`, '나') = 상대별 절 `home:{peer}` → 행 목록. 요청 개요 = `req-box`(받은 · 보낸) → '나' 면 상대별 절 `peer-fold` → 행.
  주고받은 메시지 = 상대별 절 `peer-msgs` → 행 + "더 보기". 들여쓰기 규칙: `.req-box .peer-fold > summary { padding-left: var(--sp-6) }`(요청 2단계 머리만),
  행 목록(`ol.rows`)은 들여쓰기 없음. 설정 트리는 `#settings_tree ul ul { padding-left: var(--sp-4) }`.
- **설정 '연결 → 초대 생성'**(트리 `view.js` `settingsTree` · 새로 만들기 메뉴 `focus: "window_btn"`) — `#settings/invite_make` 로 가서 `#invite_make` 로 스크롤 ·
  `window_btn` 에 초점만. **누르지 않는다**(초대 생성 `POST /api/pairing-window` 는 `window_btn` 클릭에서만 — 5분 동안 첫 요청 1건 자동 등록).
- **설정 '연결 → 초대 수락'** — 라우터(`app.js` 경로 처리 끝) `if (r.view === "settings" && r.focus === "invite_accept") showAccept(true)` 만 있고 닫는 곳은
  `accept_btn` 토글뿐 → 다른 설정 항목 · 다른 화면으로 가도 `#invite_accept` 가 펼친 채 남는다. 레일 "+"(`rail_add`)도 펼친다.
- **에이전트 등록** — `agent_new_btn`(머리 오른쪽) → `#agent_new`(이름 · 폴더 · 도구 · 추가 지시 · 등록, `grid` 폼) 를 목록 `#agent_groups` **뒤**에 보이고 숨긴다.
  자리는 이미 목록 아래지만 모양은 목록 줄(`manageItem` — 타일 · 이름 · 부제 · "관리")과 다른 맨 폼.
- **"관리" 단추** — `manageItem` 의 글자 단추 "관리"(펼침 토글) — **연결 목록(상대)과 내 에이전트 둘 다** 같은 함수.
  이미 연필(`ico-pencil` · `PENCIL_SVG`)인 편집: 타일 편집 · 제목 편집 · 그룹 이름 바꾸기 · 본문 편집 · 내 에이전트 편집(상대 메뉴). 글자만인 편집: 대화 "편집"
  (`edit_btn` — 여러 글 고르기 모드 토글, `aria-pressed`).

## 범위

- 새 대화 폼 — "내 응답 에이전트" 줄 + 하위 줄 "최대 응답 횟수"(에이전트를 고를 때만) · 줄마다 라벨 아이콘.
- 접이식 들여쓰기 — 개요 · 요청 개요 · 주고받은 메시지의 하위 절 · 행.
- 설정 알림 "자동 왕복" ? 설명.
- 설정 '초대 생성' 메뉴 = 초대 만들기 · '초대 수락' 칸 접기 규칙.
- 내 에이전트 등록 칸 = 목록 줄 모양 "새 에이전트" 줄.
- 연필 통일 — `manageItem` "관리" · 대화 "편집".
- 아이콘 없는 메뉴에 아이콘 — 프로필 메뉴 · 내 활동 · 요청 탭(결정 11).
- 매뉴얼(user-guide · web-ui) · `ux_literals` 잠금 · node 테스트.

## 제외

- 기능 이름 "자동 왕복"(설정 · 세부정보 · 대화 상태 · 매뉴얼 10장 제목) · API · DB · CLI — 그대로(결정 2).
- 메뉴가 아닌 단추(저장 · 취소 · 삭제 · 보내기 · 수용/반려 글자 단추)와 보기 토글(대화 보기 · 원문 보기) · 설정 카드 제목 — 아이콘 추가 안 함.
- 새 그림 — `gear`(설정, 레일 설정 단추와 같은 그림) · `title`(제목) 둘만 새로 넣고 그 밖은 기존 28종.

## 성공 기준

- A1: 새 대화 폼에 "자동 왕복" 낱말이 없고 "내 응답 에이전트" 줄이 있다. "최대 응답 횟수"(기본 10, 1 ~ 50)는 그 아래 한 단 들여쓴 줄로, "안 함" 이면 숨고 에이전트를 고르면 보이며 보낼 때 그 값이 `relay_cap` 으로 간다.
- A2: 새 대화 폼의 줄 라벨마다 아이콘이 있다.
- A3: 개요 · 요청 개요 · 주고받은 메시지에서 하위 절 머리와 행이 상위보다 단계마다 한 단씩 들여쓰이고 하위 절 왼쪽에 안내선이 있다(좁은 화면은 더 좁게).
- A4: 설정 알림 "자동 왕복" 옆 ? 에 마우스를 올리거나 초점을 주면 기능 설명과 세 옵션(시작과 끝 · 메시지마다 · 알리지 않음) 설명이 보인다.
- A5: 설정 트리 · 새로 만들기의 "초대 생성" 을 누르면 초대가 만들어진다(초대 상자 · 안내 문구). 같은 해시로 새로 고침 · 뒤로 가기로 와서는 만들지 않는다.
- A6: "초대 수락" 칸은 메뉴 "초대 수락" · 레일 "+" · `accept_btn` 으로 펼치고, 다른 설정 항목 · 다른 화면으로 가면 접힌다.
- A7: "에이전트 등록" 을 누르면 목록 마지막 줄 아래에 목록 줄 모양의 "새 에이전트" 줄(펼친 상세 = 이름 · 폴더 · 도구 · 추가 지시 · 등록 · 취소)이 나오고, 등록하면 닫히고 목록에 그 줄이 생긴다.
- A8: 연결 목록 · 내 에이전트 줄의 "관리" 가 연필 아이콘 단추(이름 "{이름} 관리", 펼침 `aria-expanded`)이고, 대화 "편집" 단추는 연필 + "편집" 이다.
- A9: 프로필 메뉴(사용자 정보 · 프로필 편집 · 알림 일시 중지 · 설정) · 내 활동 탭 · 요청 탭의 항목마다 아이콘이 있다.
- A10: 기존 검증 명령(cargo test · node 테스트 · 문서 · gate 체커)이 green 이다.

## 결정

1. 새 대화 상한 = "내 응답 에이전트" 아래 한 단 들여쓴 하위 줄 **"최대 응답 횟수"**(값 10 · 1 ~ 50), "안 함" 이면 숨김. 새 대화에는 "자동 왕복" 낱말 없음.
2. 다른 곳의 "자동 왕복" 은 그대로(기능 이름). 설정 ? 설명이 "내 응답 에이전트" 와 잇는다. 기본 상한 라벨도 그대로.
3. 새 대화 줄 아이콘 — 상대 `user` · 상대 에이전트 `bot` · 내 응답 에이전트 `swap` · 최대 응답 횟수 `reset` · 제목 `title`(새) · 메시지 `chat` · 메시지 종류 `inbox`.
   (권장안의 제목 `pencil` 은 결정 8 의 "연필 = 편집" 과 겹쳐 `title` 로 바꿈 — 구현자 해석, 시안에서 확인.)
4. 접이식 = 단계마다 머리 · 행을 `--sp-5` 씩 들여쓰기 + 하위 절 왼쪽 옅은 세로 안내선(`--border`), ≤ 720px 은 `--sp-3`. 개요 · 요청 개요 · 주고받은 메시지.
5. '초대 생성' 메뉴(트리 · 새로 만들기) = 누르면 `window_btn` 과 같게 초대를 만든다. 해시로 다시 올 때는 만들지 않는다(클릭 때만).
6. '초대 수락' = 메뉴 · 레일 "+" 로만 펼치고 다른 설정 항목 · 다른 화면으로 가면 접는다. `accept_btn` 토글 유지.
7. 에이전트 등록 = 목록 끝 구분선 아래 목록 줄 모양의 "새 에이전트" 줄(빈 타일 · "새 에이전트" · 펼친 상세) + 등록 · 취소. 머리 "에이전트 등록" 단추는 열고 닫음.
8. 연필 통일 = `manageItem` "관리" → 연필 아이콘 단추("{이름} 관리", 펼치면 눌림) — 연결 목록 · 내 에이전트. 대화 "편집" = 연필 + "편집". 이미 연필인 것 · 다른 동작은 그대로.
9. 설정 "자동 왕복" ? 설명 = 줄 넷(기능 · 시작과 끝 · 메시지마다 · 알리지 않음), 기존 `help-wrap` · `tip`.
10. 디자인 시안으로 1 · 3 · 4 · 7 · 8 · 9 · 11 을 확인한 뒤 plan. 시안 = 캔버스 https://claude.ai/artifact/K7BwxHgK1b9k6mkwqSCRnC(비공개 — 보드 넷: 새 대화 · 요청 개요 · 내 에이전트 · 메뉴 아이콘/도움말).
11. 아이콘 없는 메뉴(사용자 추가 지시) — 조사 결과 사이드바 · 설정 트리 · 새로 만들기 · 타일 · 대화 · 그룹 · 컨텍스트 메뉴는 이미 아이콘이 있다. 없는 것:
    프로필 메뉴 "사용자 정보" `user` · "프로필 편집" `pencil` · "알림 일시 중지" `bell` · "설정" `gear`(새 — 레일 설정 단추 그림)(상태 항목 셋은 색 점 유지),
    내 활동 탭 "전체" `bell` · "받은 요청" `arrow-down` · "내 요청" `arrow-up` · "받은 답" `chat` · "실패" `x`, 요청 탭 "받은 요청" `arrow-down` · "보낸 요청" `arrow-up`.
    메뉴가 아닌 단추 · 보기 토글 · 카드 제목은 제외(구현자 해석 — 시안에서 확인).
