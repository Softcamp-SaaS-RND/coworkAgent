  메시지 4(사람 24 · 28자, 에이전트 답 609자 · 3,209자 — 긴 답은 제목 8 · 목록 35 · 표 7줄 · 굵게). 이름 · PC · IP · 지문 · 경로 ·
  본문은 같은 길이 · 구조의 가짜 값으로 바꿨다(실제 본문은 게시하지 않음).
- 모든 시안이 같은 정보 구조를 그린다 — 레일(나 · 상대) · 대화 목록 검색 · 대화 / 보낸 메시지 / 타임라인 탭 · markdown 답(제목 · 목록 ·
  표) · 원문 보기 · 작성창 편집 / 미리보기 · 설정 트리 · 키·값 표(읽기 전용 표시) · 실행 기본값(model · effort) · 연결 목록 그룹
  아코디언(상대별 model · effort · 도구 편집 바로가기 · 삭제) · 에이전트 편집(이름 읽기 전용) · 알림 정렬 · "대화 턴에 대한 상한 기본값".
  시안끼리는 톤 · 매너(색 · 글꼴 · 밀도 · 모서리 · 강조 방식)가 다르다.
- 실데이터의 긴 답에 **표**가 있다 — plan 설계의 markdown 범위에 표를 더한다(plan 개정 1, 평가 항목 변경 없음).
