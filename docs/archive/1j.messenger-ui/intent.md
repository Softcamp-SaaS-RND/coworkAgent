## 왜

글 · 북마크 단추) 기대대로 동작하지 않는다(머리 북마크 단추는 북마크하지 않음 · 프로필 '나 나' · 타일을 누른 뒤 Alt + ↑ / ↓ 안 됨). 연결 목록의 그룹은 자유
입력 칸이라 고를 데가 없고 레일 그룹과 따로 논다. 메신저처럼 대화방마다 이어지는 말풍선 화면으로 바꾸고 메뉴 · 설정을 정리한다.

## 범위

- 대화 보기 — 메신저형 말풍선(내 글 오른쪽, 상대 사람 · 에이전트 글 왼쪽 + 이름 · 아바타, 날짜 구분선), 대화방(대화) 하나에 주고받은 글이 이어진다.
- 대화 머리 — "대화 보기" · "원문 보기" 전환 · "북마크 n"(이 대화의 북마크 목록 열기) · "세부정보" · 제목 옆 ☆. "보낸 메시지" 탭 없앰.
- 말풍선 우상단 아이콘 — 북마크(넣기 · 빼기, 북마크한 글은 늘 보임) · 복사. 아래 단추 줄의 "북마크" · "복사" 없앰.
- 대화방 목록 — '보냄' · '받음' 표시 없이 아바타 · 제목 · 마지막 글 미리보기 · 시각 · 안 읽음, 제목 왼쪽 ☆ 넣기 · 빼기(회색 · 노랑).
- 사이드바 메뉴 — '나' 개요 / 내 활동 · 요청 · 주고받은 글(상대별 절) / 즐겨찾기 · 북마크 항목 · 에이전트, 상대 타일 · 그룹 타일에서 "주고받은 글" 없앰,
  "즐겨찾기" 화면(★ 대화방).
- 주고받은 글 — "사람 → 에이전트" 같은 라벨 없이 이름 · 시각 · 대화방 제목.
- 상단 바 — "받기 가능" 칩 없앰, 프로필 아이콘 테두리 · 점 색으로 상태(초록 받기 가능 · 주황 집중 · 붉은 앱 연결 끊김), 프로필 메뉴에서 상태 고르기, 이름 한
  번만('나 나' 고침).
- 레일 타일 아이콘 A안 — 사람 모양(나 · 상대) · 사람 + 그림자(그룹), 이름은 타일 아래, 그림을 넣으면 그림.
- 상대 그룹 — 상대 타일 메뉴 "그룹" 체크 · 연결 목록에서 그룹 사이 끌어 옮기기 · "그룹 ▾" · 그룹 추가 · 이름 바꾸기 · 삭제 — 레일 그룹 타일에 바로 반영.
  상대를 넣은 그룹에는 그 상대의 대화 전부(앞으로 생길 대화 포함)가 보인다.
- 타일 메뉴 "위로 옮기기 · 아래로 옮기기", 타일을 누른 뒤에도 Alt + ↑ / ↓ 동작(초점 유지).
- 설정 — "페어링"(초대 생성 · 초대 수락 같은 모양) · "주소 · 코드로 직접 추가" 없앰 · 내 정보 "읽기 전용" 없앰 · 내 에이전트 그룹 칸 · "그룹 없음" 없앰.
- README · 매뉴얼 · 캡처.

## 제외

- 대화방 모델 변경(같은 주제를 양쪽이 따로 연 두 대화를 하나로 합치기) — 대화(대화방) 하나 = 지금의 대화 하나.
- 통계 메뉴(별도 Task 후보).
- 피어 프로토콜 · CLI 변경 — 상대 그룹 · 즐겨찾기는 이 PC 에만.
- 내 에이전트 묶기(에이전트는 레일 타일이 아니다).

## 성공 기준

- A1: 대화를 열면 글이 말풍선으로 보인다 — 내 글은 오른쪽, 상대 사람 · 에이전트 글은 왼쪽에 이름과 함께, 날짜가 바뀌면 구분선 — 말풍선 · 목록에 "사람 →
  에이전트" 같은 방향 라벨이 없다.
- A2: 대화 머리에 "대화 보기" · "원문 보기" · "북마크 n" · "세부정보" 가 있고 "보낸 메시지" 는 없다 — "북마크 n" 은 이 대화의 북마크 목록을 연다(n = 이 대화에서
  북마크한 글 수).
- A3: 말풍선 우상단 북마크 아이콘을 누르면 그 글이 북마크 항목에 들어가고 다시 누르면 빠진다(북마크한 글은 노란 아이콘이 늘 보임), 복사 아이콘은 본문을
  복사한다 — 말풍선 아래 "북마크" · "복사" 단추가 없다.
- A4: 대화방 목록 줄에 '보냄' · '받음' 표시가 없고, 제목 왼쪽 ☆ 로 즐겨찾기를 넣고 빼며, 대화 머리 ☆ 와 같은 상태다.
- A5: 사이드바 메뉴 — '나' = 개요 | 내 활동 · 요청 · 주고받은 글 | 즐겨찾기 · 북마크 항목 · 에이전트, 상대 타일 = 요청 | 즐겨찾기 · 북마크 항목 · 에이전트,
  그룹 타일 = 개요 | 요청 | 즐겨찾기 · 북마크 항목. "즐겨찾기" 는 그 범위의 ★ 대화방을 보인다. '나' 의 주고받은 글은 상대별 절이다.
- A6: 상단 바에 "받기 가능" 칩이 없고, 프로필 아이콘 색이 상태를 보인다(받기 가능 초록 · 집중 주황 · 앱과 연결 끊김 붉은) — 프로필 메뉴에서 받기 가능 · 집중을
  고른다. 표시 이름은 한 번만 보인다.
- A7: 레일 타일이 사람 모양(나 · 상대) · 사람 + 그림자(그룹) 아이콘에 이름이 아래에 있고, 그림을 넣은 타일은 그림이다.
- A8: 상대 타일 메뉴 "그룹" 체크 · 연결 목록 끌어 옮기기 · "그룹 ▾" 로 상대를 그룹에 넣고 빼면 그 그룹 타일 화면에 그 상대의 대화 전부(뒤에 생긴 대화
  포함)가 보이고, 연결 목록 · 레일이 바로 바뀐다. 연결 목록에서 그룹을 추가 · 이름 바꾸기 · 삭제(대화 · 연결은 남음)하면 레일 그룹 타일에 바로 반영된다.
- A9: 타일을 마우스로 누른 뒤 바로 Alt + ↑ / ↓ 로 자리가 바뀌고, 타일 메뉴 "위로 옮기기 · 아래로 옮기기" 도 같다. 끌어 놓기도 된다.
- A10: 설정 — "페어링" 의 "초대 생성" · "초대 수락" 이 같은 모양이고 "주소 · 코드로 직접 추가" 가 없다, 내 정보에 "읽기 전용" 이 없다, 내 에이전트 · 연결
  목록에 자유 입력 그룹 칸 · "그룹 없음 n" 머리가 없다.
- A11: 루트 `PROJECT.md` 검증 명령이 모두 통과한다.
