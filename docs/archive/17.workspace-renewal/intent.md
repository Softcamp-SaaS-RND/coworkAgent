# intent — 17.workspace-renewal

## 왜

사용자 지시(2026-10-12) — 원문 "사용자 UI/UX 리뉴얼. 제공 기능은 다음의 slack 기능 참고하여 제공가능한 기능 목록검토 후 반영.
… 폰트/색상만 변경하지 말고 화면 전체를 디자인해서 제안할 것." Slack 빠른 시작 가이드 기능 24개를 검토(반영 15 · 제외 9)해 시안 1안(Nocturne)을
게시했고, 검토 회신 6건을 받았다(`## 결정` 라운드 0). 시안 · 검토표: [검토 아티팩트](https://claude.ai/artifact/REnpPvZSZLnMHVcrAEc4ob) ·
Superdesign draft `d4b76d08-f1a7-4dd2-89c3-ab0d5bfd714b` v4. 닿는 [masterPlan](../../masterPlan.md) 항목: S4(슬랙형 UI) · D26(시안 A 기본 + C 타임라인) ·
D27 · D29(알림). 상대 PC 에게 보이는 동작(집중 · @멘션)은 [18.focus-mention](../18.focus-mention/intent.md) 으로 나눴다(라운드 1).
이 Task 가 없으면 S4 의 슬랙형 UI 가 [15.ux-refresh](../../archive/15.ux-refresh/intent.md) 까지의 3단 배치에 머물고, 검토에서 반영하기로 한 기능(내 활동 ·
즐겨찾기 · 저장 · 통합 검색 · 실행 상세)이 없다.

## 범위

시안 v4 의 메인 작업 화면 — 이 PC 안에서 끝나는 화면 · 데이터만(상대에게 보이는 동작은 18).

- **배치** — 상단 바 · 레일 · 사이드바 · 대화 · 실행 상세 5영역(데스크톱 1440 × 900 기준). 15 에서 정한 것은 유지(`## 결정` 유지 목록).
- **상단 바** — 통합 검색(Ctrl K — 메시지 본문 · 대화 제목 · 사람(PC) · 에이전트) · "+ 새로 만들기"(새 대화 · 자동 왕복 대화 · 초대 생성 · 초대 수락 ·
  에이전트 등록) · 알림 · 내 프로필 메뉴(표시 이름 · 아이콘 · 알림 일시 중지 · 환경설정). 내 상태(받기 가능 / 집중)는 18.
- **사이드바** — 고른 타일 머리(이름 ✎) · 내비(대화 · 내 활동 · 저장된 항목 · 에이전트) · 제목 검색 · 섹션(★ 즐겨찾기 · 대화 · 상대 에이전트, 접기) ·
  대화 행(방향 태그 · 상태 · 실행 중 · 왕복 칩 · 안 읽음).
- **내 활동** — '받은 글' 을 대체: 상대 쪽 글 + 자동 왕복 시작 · 끝 + 실패, 최신순, 안 본 수 배지.
- **대화** — 머리글(방향 태그 · 제목 ✎ · ★ · 상대 · 에이전트 · model · effort) · 탭 대화 / 보낸 메시지 · 원문 보기 하나 · 메시지 작업(저장 · 복사 ·
  다시 보내기) · 실행 중 표시 · 입력창(굵게 · 목록 · 코드 · Enter 보내기 · Shift+Enter 줄바꿈). @멘션은 18.
- **실행 상세 패널** — 고른 요청의 진행(보냄 → 대기열 → 실행(model · effort · 턴 · 시간) → 응답) · 대화 정보 · 자동 왕복 진행과 멈춤 · 저장된 항목.
  타임라인 탭을 대신한다.
- **이 PC 에만 저장** — ★ 즐겨찾기 · 저장된 항목 · 알림 일시 중지.

## 성공 기준

- A1: 메인 화면이 상단 바 · 레일 · 사이드바 · 대화 · 실행 상세 5영역으로 그려지고, 영역별 라벨이 시안 v4 와 글자 그대로 같다(18 몫인 상태 칩 ·
  @멘션 제외, 라벨 목록은 plan 에 고정).
- A2: 통합 검색(Ctrl K)이 메시지 본문 · 대화 제목 · 사람(PC 표시 이름) · 에이전트 이름을 찾고, 결과를 누르면 그 대화(메시지면 그 위치)로 간다.
  사이드바 '제목 검색' 은 지금처럼 제목으로만 거른다.
- A3: 내비 '내 활동' 이 '받은 글' 을 대체한다 — 상대 쪽 글 · 자동 왕복 시작 · 끝 · 실패가 최신순으로 보이고 안 본 수가 배지로 보인다. 화면에
  '받은 글' 라벨이 없다.
- A4: 대화 머리글 ★ 로 즐겨찾기를 켜고 끄며, 켠 대화는 사이드바 '★ 즐겨찾기' 섹션에 보인다. 이 PC 에만 저장하고 상대에게 보내지 않는다.
- A5: 메시지 작업 '저장' 으로 저장한 메시지가 '저장된 항목'(사이드바 내비 · 실행 상세)에 모이고 해제된다. 이 PC 에만 저장한다.
- A6: 메시지 작업 '복사' 는 본문을 클립보드로, '다시 보내기' 는 내 글을 같은 대화에 새 요청으로 보낸다. 메시지별 편집 · 삭제 · 원문 버튼은 없다.
- A7: 입력창의 굵게 · 목록 · 코드 버튼이 markdown 표기를 넣고, Enter 는 보내기 · Shift+Enter 는 줄바꿈이며 한글 조합 중 Enter 는 보내지 않는다.
- A8: 실행 상세 패널에 고른 요청의 진행(보냄 → 대기열 → 실행(model · effort · 턴 · 시간) → 응답) · 대화 정보 · 자동 왕복 진행과 멈춤 · 저장된 항목이
  보인다. '타임라인' 탭은 없다.
- A9: "+ 새로 만들기" 메뉴의 다섯 항목(새 대화 · 자동 왕복 대화 · 초대 생성 · 초대 수락 · 에이전트 등록)이 각 화면으로 간다.
- A10: 프로필 메뉴에 표시 이름 · 아이콘 · 알림 일시 중지 · 환경설정이 있다. 알림 일시 중지 동안 브라우저 알림 · 트레이 표시가 나가지 않고 해제하면
  다시 나간다. 이 PC 에만 저장한다.
- A11: 15 에서 정한 결정이 유지된다 — `## 결정` 유지 목록(기존 테스트 green + 라벨 literal 테스트).
