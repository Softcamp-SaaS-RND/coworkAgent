## 범위

- **요청 보드**(D39 ①): '요청' 화면에 목록 / 보드 보기 전환. 보드 열 = 대기 · 수용 · 반려 · 완료, 열 머리 건수 = 서버 집계(`req_counts`), 카드 = 지금 요청 행 내용(상대 · 제목 · 본문 앞부분 · 시각 · 메모).
- **끌어 놓기로 상태 바꾸기**: 받은 요청 카드만, `reqMoves` 가 허용하는 열에만 놓인다(대기 → 수용 · 반려, 수용 → 완료). 놓으면 지금의 메모 한 줄 칸이 열리고 확인해야 요청자에게 간다(취소면 제자리). 보낸 요청 보드는 읽기 전용.
- 카드의 글자 단추(수용 · 반려 · 완료 · 다시 알리기)는 남긴다 — 마우스 없이 바꾸는 길(접근성 기본).
- 허용 판정은 `view.js` 순수 함수(열 → 놓기 가능)로 두고 node 시험.
- **대화 목록**(나 · 상대 타일): `dir = out` 만 머리("내 대화") 없이 보인다. 공유 대화는 지금처럼 "공유 대화" 머리 + 줄. 그룹 타일은 지금대로(내 대화 · 에이전트 대화 · 공유 대화 머리).
- **사이드바 '에이전트' 하위 메뉴**(나 · 상대 타일): "등록된 에이전트"(지금 `#agents` 화면) · "에이전트 대화"(새 화면).
- **에이전트 대화 화면**: 고른 타일 범위의 `dir = in` 대화를 **요청한 상대**별 절로(즐겨찾기 화면처럼 절 + 대화 줄). 상대 타일이면 그 상대 절 하나.
- **요청 피드백 말풍선**: 상태가 대기가 아닌 요청 바로 아래에 별도 말풍선 하나 — 지금 상태 · 메모 · 바뀐 시각(`req_at`), 받은 쪽 사람 쪽(요청자 PC 는 왼쪽, 받은 PC 는 오른쪽).
  상태가 바뀌면 그 말풍선이 바뀐다. 요청 말풍선 위 "요청 · {상태}" 태그는 남기고 "메모: …" 는 뺀다. 저장 · 프레임 변경 없음.
- **입력창**(시안 A 차용): 대화 입력창(`#reply_form`)을 A 모양으로 — 최대 폭 860px · 옅은 그림자 · 질의 / 요청을 라디오 대신 **세그먼트**(같은 라디오 입력, 모양만),
  서식 단추 · 키 안내 · 보내기 자리는 A 순서(서식 | 빈칸 | 질의·요청 | 키 안내 | 보내기). 색은 지금 토큰(다크 · 라이트 그대로).
  안내 문구 "@ 로 상대 에이전트 부르기"(`#mention_hint`)는 지우고 A 의 placeholder 안내도 넣지 않는다 — placeholder 는 지금 "메시지 입력" 그대로. @멘션 기능(D19)은 그대로.
- **웹UI 편집 모드 삭제**: 입력창 위 "편집" 단추 · 편집 막대(n개 선택 · 삭제 · 완료) · 반영 범위 대화상자 · 말풍선 체크박스 · 본문 연필을 지운다. 서버 API · CLI 편집 · 삭제 · "(편집됨)" 표시는 그대로.
- 문서: [web-ui.md](../../manual/dev/web-ui.md)(요청 화면 · 대화 목록 · 내비), PRODUCT.md 손댄 절, 종결 시 masterPlan D35 · D39 ① 환류.

## 성공 기준

- A1: 보드 열 = 대기 · 수용 · 반려 · 완료 순, 열마다 그 상태 카드 · 머리 건수 = 서버 집계(node 시험).
- A2: 받은 요청 카드는 `reqMoves` 허용 열에만 놓을 수 있고(대기 → 수용 · 반려, 수용 → 완료), 그 밖의 열 · 보낸 요청 카드 · 같은 열은 놓을 수 없다(node 시험).
- A3: 놓으면 메모 칸이 열리고 확인해야 지금의 `req:{상태}` 경로로 간다, 취소면 상태 그대로(실화면 — 19 인수로 미룰 수 있음).
- A4: 목록 / 보드 전환이 되고 목록 보기는 지금 목록과 같다(글자 단추 · 메모 · 다시 알리기 유지).
- A5: 나 · 상대 타일 대화 목록에 `dir = in` 대화가 없고 "내 대화" 머리가 없다, 공유 대화 머리는 남는다, 그룹 타일은 지금대로(node 시험 — `conv_split_rows` · `share_groups` 기대값이 바뀐다).
- A6: 사이드바 '에이전트' 아래 "등록된 에이전트" · "에이전트 대화" 두 항목(나 · 상대 타일), 그룹 타일엔 없음(node 시험 — `sideNav`).
- A7: 에이전트 대화 화면 = 범위의 `dir = in` 대화를 요청한 상대별 절로, 상대 타일이면 그 상대만(node 시험).
- A8: 피드백 말풍선 — 대기면 없고, 수용 · 반려 · 완료면 요청 바로 아래 하나(상태 · 메모 · 시각), 방향 = 받은 쪽 사람 쪽, 요청 말풍선 위에 "메모:" 없음 · 태그는 남음(node 시험).
- A9: 입력창 — 질의 / 요청 세그먼트(라디오 2개 그대로) · `#mention_hint` 없음 · placeholder "메시지 입력" · 최대 폭 860px(node 정적 시험 — index.html · app.css).
- A11: 웹UI 에 편집 모드가 없다 — `index.html` 에 `edit_btn` · `edit_bar` · `scope_dialog` 없음, `app.js` 에 `setEditMode` 없음(정적 검사).
- A10: 회귀 없음 — PROJECT.md 검증 명령 PASS.
