## 범위

- 말풍선 A: 사람 글 = 색 면(내 글 강조색 층 · 상대 글 `--recv-bg`), 에이전트 글 = 흰 면(`--surface`) + 에이전트 색 테두리 + 이름 옆 "에이전트" 칩, 좌 · 우 어느 쪽이든 같다.
- 에이전트 말풍선 옆 에이전트 아이콘(로봇) 아바타 — 내 쪽(오른쪽) 에이전트 답에도.
- 대화 목록 A: 사이드바 바탕과 구별되는 카드 줄, 미리보기 앞 마지막 발화자 아이콘(에이전트 = 로봇 · 에이전트 색, 사람 = 사람). 사이드바 메뉴 구성은 그대로.
- 주고받은 메시지 · 에이전트 대화 등 목록 줄에도 사람 / 에이전트 구분(아이콘).
- 입력창: 좌우 여백 = 말풍선 영역과 같은 `max(48px, 8%)`, 스크롤 영역 밖 24px 간격, 글 칸 44px 에서 시작해 200px 까지 늘어남.
- 의견: 화면 · 서버 오류 문구의 "피드백" · 요청 "메모" → "의견", 칸 = 3줄 textarea · 글자 수 · 확인 / 취소 44px, Enter 확인 · Shift+Enter 줄바꿈, 줄바꿈 저장 · 표시(pre-wrap),
  이전 버전 상대와 호환.
- 레일 오른쪽 손잡이 끌기(· ← → 키): 끄는 동안 폭이 따라가고 120px 기준으로 아이콘이 바뀜, 놓으면 72px(크게) · 168px(작게)로 맞추고 `ui_tile_size` 저장 · 설정 선택 동기화.
  설정 "타일 크기" 표시 "보통" → "크게".
- 레일 사용자 타일 · 그룹 타일을 포인터로 끌어 놓아 순서 바꾸기(같은 묶음 안) — 지금 HTML 끌어 놓기(`draggable`)를 포인터 끌기로.
- 설정 "연결 목록" → "그룹설정"(트리 · 카드 제목 · 안내 · 오류 · OS 알림 문구 · 매뉴얼 · README).
- 그룹설정 카드 = 시안 A: 왼쪽 칸 그룹 · 사용자 한 줄 목록(대화 수 · 접속 점), 오른쪽 칸 고른 항목 상세(그룹 = 대화 줄 · 이름 바꾸기 · 삭제, 사용자 = 관리 줄 · 대화),
  검색 = 그룹 이름 · 사용자(이름 · PC · 지문) · 대화 제목, 대화 줄을 왼쪽 그룹 줄에 끌어 놓으면 그 그룹에 넣기.
- 매뉴얼 · README · masterPlan(S4 · S1 · D35 · D37) 반영.

## 제외

- 에이전트 실행 프롬프트의 "대화 메모"(실행 요청 아닌 사람 글) — 요청 의견과 다른 개념, 그대로.
- 상대 타일 색 말풍선 층(`data-tone`) 재도입 — 시안 A 는 사람 글 색을 주고받는 방향으로만 가른다.
- 레일 연속 폭 저장 · "자동" 타일 크기 값(질문 답 — 크게 / 작게만).
- 좁은 화면(720px 이하) 레일 끌기 — 그 화면은 레일이 가로 줄이라 손잡이를 숨긴다.
- 그룹설정 대화 줄 끌기(HTML 끌어 놓기 그대로 — 놓는 자리만 왼쪽 그룹 줄로 바뀐다) · 사용자 타일과 그룹 타일 사이 옮기기('나' 고정 · 묶음 순서는 설정 "타일 순서").

## 성공 기준

- A1: 사람 글과 에이전트 글의 말풍선이 다르다 — 에이전트 글은 흰 면 + 에이전트 색 테두리 + "에이전트" 칩, 사람 상대 글은 `--recv-bg` 면, 내 사람 글은 강조색 층(검사 · 시험).
- A2: 에이전트 글 말풍선 옆에 로봇 아이콘 아바타가 있다 — 내 쪽 에이전트 답 포함(검사 · 실 화면).
- A3: 대화 목록 줄이 카드 모양이고 미리보기 앞에 마지막 발화자 종류 아이콘(에이전트 · 사람)이 붙는다(node 시험 · 검사).
- A4: 주고받은 메시지 · 활동 등 메시지 줄에 사람 / 에이전트 구분 아이콘이 붙는다(node 시험 · 검사).
- A5: 입력창 좌우 여백 `max(48px, 8%)`(말풍선 영역과 같음) · 글 칸 최소 44px · 최대 200px 자동 늘어남 · 스크롤 영역과 입력창 사이 24px(스크롤 안쪽 패딩 아님)(검사 · 실 화면).
- A6: 사용자에게 보이는 "피드백" · 요청 "메모" 0건, "의견" 으로(웹UI · 서버 오류 문구 · 매뉴얼 · README)(검사).
- A7: 의견 칸 = 3줄 textarea · maxlength 200 · "n / 200" · 확인 · 취소 높이 44px · Enter 확인 · Shift+Enter 줄바꿈(한글 조합 중 Enter 는 확인 아님)(검사 · node 시험).
- A8: 의견 줄바꿈이 저장되어 요청자에게 그대로 가고(새 버전끼리) 이전 버전 검사(`clean_label`)도 통과하는 형태로 보낸다, 다른 제어 문자 · 201자는 거부, 의견 표시는 줄바꿈 보존(Rust 시험 · 검사).
- A9: 레일 손잡이 끌기 · ← → 키로 타일 크기가 바뀌어 저장되고(놓으면 72 · 168px), 설정 선택이 따라 바뀐다, 기준 120px(경계 119 · 120 · 121)(node 시험 · 검사).
- A10: 회귀 없음 — PROJECT.md 검증 명령 PASS.
- A11: 레일 사용자 · 그룹 타일을 누른 채 5px 이상 끌면 끌기가 되고(그 미만은 그냥 누름), 같은 묶음 타일 위에 놓으면 그 앞 · 뒤로 옮겨 저장된다, 끈 뒤에는 타일 고르기가 일어나지 않는다,
  타일에 HTML 끌어 놓기(`draggable`)가 없다(node 시험 · 검사).
- A12: 사용자에게 보이는 "연결 목록" 0건, "그룹설정" 으로(웹UI · OS 알림 · 매뉴얼 · README)(검사).
- A13: 그룹설정 = 왼쪽 그룹 · 사용자 목록 + 오른쪽 고른 항목 상세, 검색이 그룹 이름 · 사용자 · 대화 제목에 맞고, 고른 항목이 사라지면 첫 그룹 → 첫 사용자 → 없음(node 시험 · 검사).

## 결정

1. 말풍선 · 대화 목록 = 시안 A(색 면 · 카드) — 기각: B(바탕 대비 · 구분선 행), C(이름 띠 · 아바타 2줄).
2. "구분" = 사람 ↔ 에이전트 구분, 사이드바 메뉴(개요 · 주고받은 메시지 · 에이전트 대화 …)는 유지(U3).
3. 에이전트 말풍선에 로봇 아이콘 아바타 — 양쪽 모두(사용자 추가 지시). 등록 에이전트 개별 아이콘은 없다(코드 사실) → 공통 로봇 아이콘.
4. 입력창 명세 개정(U4): 여백 `max(48px, 8%)` · 간격 24px 는 스크롤 영역 밖 · 글 칸 44px → 200px. 기각: 24px 여백 유지(사용자 "비대해 보임").
5. 용어: "피드백" · 요청 "메모" 전부 "의견"(U5). 피드백 말풍선 머리 = "요청 의견 · {시각}".
6. 의견 줄바꿈: Shift+Enter 줄바꿈 · Enter 확인(입력창과 같다), 저장은 `\n`(다른 제어 문자 거부), **보낼 때 `\n` → U+2028(LINE SEPARATOR)**, 받을 때 U+2028 → `\n`.
   U+2028 은 제어 문자(Cc)가 아니라 이전 버전 `clean_label` 을 통과한다(호환성 유지 — 질문 답). 이전 버전 화면에는 줄바꿈 대신 공백 · 빈 글자로 보일 수 있다.
   기각: 줄바꿈 그대로 보냄(이전 버전이 `bad_request` 로 거절) · 한 줄로 합침(Q2 줄바꿈 보존 위배).
7. 레일 끌기: 놓으면 72 · 168px 중 가까운 쪽(U6 권장안), 120px 미만 = 크게(normal) · 이상 = 작게(small). 끌면 설정값이 바로 바뀐다(U7 "자동으로 동작"), "자동" 값 없음(질문 답).
8. 승인 절차: 이번 결정 · 질문 답을 intent 승인으로, plan 승인은 "plan 후 바로 구현" 답으로 갈음(사용자 2026-10-21).
9. (개정 2026-10-21) 레일 타일 순서 = 포인터 끌기(5px 넘게 움직이면 끌기) — HTML 끌어 놓기는 브라우저 끌기 확장이 가로챈다(#1x 대화 줄 · 요청 보드와 같은 이유). 키(Alt + ↑ / ↓) · 타일 메뉴는 그대로.
10. (개정) 이름 = "그룹설정"(사용자 원문 글자 그대로, 띄어 쓰지 않음).
11. (개정) 그룹설정 = 시안 A(목록 + 상세) — 기각: B(그룹 카드 격자 + 사용자 표).
