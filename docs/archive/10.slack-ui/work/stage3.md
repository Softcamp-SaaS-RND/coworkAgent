## 설계 결정

- 레일: "나"(내 PC = 전부) + 페어링된 PC(이름 앞 두 글자, `aria-label` 에 전체 이름) — 누르면 사이드바 대화를 그 상대로 거른다.
  `+` = 설정의 초대 붙여넣기에 초점, 톱니 = 설정.
- 사이드바: 내 PC 이름 · 지문 앞부분 / 내 에이전트 / 대화(제목 · 상대 · 상태 배지, `+` = 새 대화) / 연결 가능한 사용자(피어 표).
- 화면은 해시로만 바뀐다(`view.js` `route`) — 뒤로 가기 · 트레이 `#me` 가 그대로 동작. 대화 · 타임라인 조회는 `Latest` 로 늦은 응답을
  버린다. 받은 대화(←)는 입력창 대신 안내.
- 글꼴은 시스템 글꼴(로컬 앱 — 외부 글꼴 요청 없음), 색은 시안 A 의 따뜻한 갈색 계열을 토큰(`:root`)으로.
- 좁은 화면(≤720px): 레일이 가로 줄, 사이드바 전체 폭, 폼 한 열.
