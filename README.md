# coworkAgent

동료 PC 의 **Claude Code 에이전트에게 그 PC 의 프로젝트를 묻고 답을 받는** Windows · macOS 트레이 앱.
"이 저장소 빌드 명령이 뭐야?", "이 API 는 어디서 호출돼?" — 담당자를 붙잡지 않아도 그 PC 의 에이전트가 코드를 읽고 답한다.

![작업 화면 — 대화 · 세부정보 · @멘션 후보](docs/images/workspace.png)

> [!NOTE]
> 화면의 이름 · PC · 폴더 · 주소는 모두 가상의 예시다.

## 왜 coworkAgent 인가

| | |
|---|---|
| **웹 서버 없음** | 띄울 서버도, 관리할 계정도 없다. 각자 PC 의 앱 하나가 같은 사내망의 상대 PC 앱과 직접 연결된다. 실행 파일 하나 — 설치도 없다. |
| **AI API 비용 없음** | API 키 · 사용량 과금이 없다. 답은 답하는 사람이 이미 쓰고 있는 Claude Code 구독으로 만든다. |
| **페어링으로 코워크** | 초대 메시지 한 번으로 동료와 연결 — 서로의 에이전트에게 묻고, 내 에이전트와 상대 에이전트가 직접 주고받게 할 수도 있다. 문서로 정리되지 않은 지식도 그 프로젝트를 아는 에이전트가 답한다. |
| **대화가 서버에 쌓이지 않음** | 대화는 두 PC 에만 남는다. 회사 밖 서버에 대화 이력을 맡기거나 보관 · 삭제 정책을 따로 챙길 부담이 없다. |

## 주요 기능

| 기능 | 한 줄 | 자세히 |
|---|---|---|
| **PC 연결** | 초대 메시지를 붙여 넣으면 끝 — 5분 안에 한 번만 쓰는 초대, 지문으로 상대 확인 | [사용자 가이드 §5](docs/manual/user/user-guide.md) |
| **원격 에이전트에게 묻기** | 상대 PC 에 등록된 에이전트가 그 폴더 안에서 **읽기만으로** 답한다 | [§6 · §7](docs/manual/user/user-guide.md) |
| **이어지는 맥락** | 같은 대화에 이어 쓰면 앞 대화를 기억한 채 답한다 | [§7](docs/manual/user/user-guide.md) |
| **컨텍스트 압축** | 대화 머리에 세션 크기("42k / 1M")가 보이고, 눌러서 요약 후 새 세션(압축) · 세션 비우기 — 80% 를 넘으면 답하는 PC 가 자동 압축 | [§7.4](docs/manual/user/user-guide.md) |
| **@멘션** | 한 대화에서 상대 PC 의 다른 에이전트를 불러 답을 받는다 | [§8](docs/manual/user/user-guide.md) |
| **메신저형 대화** | 내 메시지는 오른쪽(강조색을 옅게 깐 말풍선), 상대 사람 · 에이전트 메시지는 왼쪽(가는 테두리 말풍선). 날짜가 바뀌면 구분선. 대화 목록은 내 대화 · 에이전트 대화 · 공유 대화로 나뉘고 마지막 메시지 미리보기 · 안 읽음, 즐겨찾기는 대화 머리글 ☆ | [§4 · §7](docs/manual/user/user-guide.md) |
| **공유 대화(관람자)** | 대화를 페어링된 다른 사람(5명까지)에게 보기만 하게 나눈다 — 이전 이력부터 이후 메시지 · 편집 · 삭제까지 따라가고, 빼거나 나가면 읽기 전용으로 남는다 | [§7.7](docs/manual/user/user-guide.md) |
| **기록 삭제 · 나가기** | 대화 ⋯ 메뉴 **"기록 삭제 ▸"** — "내 글만 삭제"(이 PC 의 그 대화 메시지만) · "모든 사용자 글 삭제"(상대 PC · 관람자 사본까지), 대화는 남는다. **"나가기"** — 이 PC 목록에서 그 대화를 지우고 나간다(상대 화면은 읽기 전용 "상대가 나감") | [§7.8](docs/manual/user/user-guide.md) |
| **복사 · 북마크** | 말풍선 우상단 아이콘으로 바로 북마크 · 복사(markdown 원문) | [§7.5](docs/manual/user/user-guide.md) |
| **요청 목록** | 고치기 · 만들기는 "요청" 으로 — 에이전트를 실행하지 않고 상대 PC 요청 목록에 쌓이며, 상대가 수용 · 반려 · 완료와 메모로 답한다. '요청' 을 열면 받은 요청 · 보낸 요청 개요(대기 · 수용 · 완료 · 반려 건수)부터 보이고, 요청 바로 아래 글자 단추로 답한다 — 대기 요청은 "✓ 수용" · "✕ 반려", 수용한 요청은 "✓ 완료". 상태는 네 상태 사이 어디로든 바꾼다(되돌리기 포함). 보기를 **"보드"** 로 바꾸면 대기 · 수용 · 반려 · 완료 열에 카드가 놓이고, 카드 손잡이로 끌어 놓아 상태를 바꾼다. 상태 · 피드백은 요청 아래 피드백 말풍선으로 보인다. 완료 요청은 7일 뒤 저절로 **archive** 로 옮겨져 숨고(그 전에도 "archive" 단추로 — 이 PC 에만), "archive 항목 보기" 로 따로 본다 | [§9](docs/manual/user/user-guide.md) |
| **자동 왕복** | 세션 생성에서 **"내 응답 에이전트"** 를 고르면 내 에이전트 ⇄ 상대 에이전트가 **"최대 응답 횟수"**(기본 10)까지 알아서 주고받는다 | [§10](docs/manual/user/user-guide.md) |
| **꺼져 있어도 보관** | 상대 PC 가 꺼져 있으면 내 PC 에 보관했다가 켜지면 보낸다 — "보내는 중" · "보내지 못함" 이 화면에 보인다 | [§7](docs/manual/user/user-guide.md) |
| **처리 경과** | 상대 에이전트가 일하는 동안 "처리 중 · 2턴 · Read 3 · 41초" 처럼 진행이 보인다. 요청이 몰리면 차례를 기다린다 | [§7](docs/manual/user/user-guide.md) |
| **집중 · 접속 상태** | 프로필 메뉴에서 "집중" 을 고르면 새 질의를 받지 않는다(요청 목록은 그대로 쌓인다) — 프로필 아이콘 색이 내 상태(초록 받기 가능 · 주황 집중 · 붉은 앱과 연결 끊김). 상대는 "방금 통신" · "n분 전 통신" 으로 보인다 | [§11](docs/manual/user/user-guide.md) |
| **그룹 · 자리 옮기기** | 프로젝트마다 필요한 대화만 골라 그룹으로 묶어 본다(이 PC 에만 — 한 대화는 여러 그룹에). 대화 ⋯ "그룹" 체크 · 그룹 타일에 끌어 놓기, 설정 연결 목록 **"사용자 목록"** 에서 사용자별 대화를 펼쳐 그룹 절에 끌어 놓으면 복사된다. 타일 · 대화는 끌어 놓거나 Alt + ↑ / ↓ · 타일 메뉴 "위로 · 아래로 옮기기" 로 자리를 바꾼다. 레일의 상대 · 그룹 묶음 순서는 설정 → 화면 "타일 순서"(사용자 → 그룹 · 그룹 → 사용자) | [§4.1 ~ §4.3](docs/manual/user/user-guide.md) |
| **나 · 상대별 보기** | 레일 "나" 는 모든 상대와의 내 대화 · 내 활동 · 요청 · 주고받은 메시지 · 즐겨찾기 · 북마크 · 에이전트(등록된 에이전트 · 상대가 내 에이전트에게 연 에이전트 대화)를 상대별 접이식 절로 묶어 보고(하위 줄은 한 단씩 들여 쓴다), 상대 타일은 그 상대의 개요(첫 화면) · 요청 · 즐겨찾기 · 북마크 · 에이전트만 본다. 주고받은 메시지는 상대별로 접혀 건수 · 마지막 메시지만 보이고, 펼치면 20건씩 — 머리 **"기간"**(1주 ~ 12주, 기본 4주)으로 보기만 거른다 | [§4](docs/manual/user/user-guide.md) |
| **검색 · 알림** | Ctrl K 통합 검색, 내 활동(받은 요청 · 내 요청의 상태 바뀜 · 받은 답 · 실패), 브라우저 알림 · 트레이 표시 — 설정 알림의 '?' 에 항목 설명. 상대 글 · 편집 · 진행은 알림을 꺼도 바로 화면에 반영된다 | [§12](docs/manual/user/user-guide.md) |
| **AI 에이전트용 CLI** | 내 AI 에이전트가 명령줄로 동료 에이전트에게 묻고 답을 기다린다 — 끊겨도 이어서 기다린다. `coworkAgent /?` 로 명령 · 출력 형식 · 종료 코드를 읽고 연동한다. 다른 도구의 메뉴에서 트레이 아이콘 없이 켜고 끈다(`start` · `open` · `stop`) | [§14](docs/manual/user/user-guide.md) |

## 시작하기

**필요한 것** — Windows 10/11 x64 또는 macOS 12 이상(Apple Silicon · Intel 공용), 상대 PC 와 같은 사내망. 답하는 PC(에이전트를 등록한 PC)에는 Claude Code 2.1.267 이상 설치 · 로그인.
묻기만 하는 PC 는 Claude Code 가 없어도 된다.

1. **실행** — [릴리스](https://github.com/tskimS/coworkAgent/releases)에서 `coworkAgent.exe`(Windows) 또는 `coworkAgent-macos.zip`(macOS — 풀면 `coworkAgent`)을 받아 실행하면 트레이(메뉴 막대)에 상주한다. 트레이 아이콘 **"열기"** → 브라우저에 화면이 열린다. 다음부터는 로그인할 때
   자동으로 켜지고(설정에서 끔), 비정상 종료되면 저절로 다시 켜진다.
2. **연결** — 한쪽이 **"+ 새로 만들기"** → **"초대 생성"**(설정 → 연결 → "초대 생성" 도 같다 — 누르면 바로 초대가 만들어진다) → **"초대 복사"** 로 메신저에 보내고,
   상대가 **"초대 수락"**(레일 "+")을 눌러 붙여 넣고 **"수락"**.
3. **에이전트 등록**(답하는 쪽) — 설정 → 내 에이전트 → **"에이전트 등록"** → 목록 아래 **"새 에이전트"** 줄에 이름 · 프로젝트 폴더 → **"등록"**. 등록한 에이전트는 줄의 ✎ 로 고친다.
4. **묻기** — **"+ 새로 만들기"** → **"세션 생성"** → 상대 · 상대 에이전트 → **"생성"**("내 응답 에이전트" 는 보통 "안 함" — 자동 왕복을 쓸 때만) → 열린 대화의 입력창에 질문 → **"보내기"**.

## 다른 AI 도구와 연동

Claude Code · Codex 같은 AI 도구가 명령줄로 coworkAgent 를 부른다. 도구에 먼저 `coworkAgent /?` 를 실행하게 하면 명령 · 옵션 · `--json` 출력 형식 ·
종료 코드를 읽고 스스로 연동한다 — 앱이 꺼져 있어도 나온다(`-h` · `--help` 도 같다).

```powershell
coworkAgent /?                                                              # 명령 · 옵션 · JSON 형식 · 종료 코드
coworkAgent peers --json                                                    # 연결한 상대
coworkAgent ask user-b "이 저장소의 빌드 명령은?" --agent review --id build-q1 --json  # 묻고 답을 기다린다
```

- AI 도구에 줄 지시 예: "`coworkAgent /?` 를 실행해 사용법을 읽고, 동료 PC 에이전트에게 물을 때는 `coworkAgent ask` 를 `--json` · `--id` 와 함께 써라."
- 결과는 표준 출력, 진행 · 오류는 표준 오류로 나온다 — 사람이 명령 프롬프트에서 직접 볼 때는 `coworkAgent /? | more`.

## 알아 둘 점

- 상대의 질문은 **답하는 PC 의 Claude 구독 사용량**을 쓴다. 압축도 요약을 한 번 실행하므로 같은 사용량을 쓴다.
- 컨텍스트 압축 · 비우기는 **두 PC 모두 0.5.0 이상**이어야 한다. 상대가 0.4.0 이하면 크기는 "알 수 없음", 요청은 거절 안내가 뜬다. 그 밖의 기능은 버전이 달라도 주고받는다.
- 공유 대화(관람자)는 **넣는 PC 와 관람자 PC 모두 0.6.0 이상**이어야 한다. 관람자가 0.5.0 이하면 "상대 앱 업데이트 필요" 로 넣지 못한다(원 상대가 0.5.0 이하면 관람자 수 알림만 가지 않는다). 0.6.0 은 DB 를 스키마 20 으로 올린다 — 올리기 전 사본(`.v19.bak`)을 남긴다.
- 0.7.0 은 화면(글꼴 · 색 · 간격 · 메뉴 이름)만 바꿨다 — 통신 · DB 형식은 0.6.0 과 같아 섞어 써도 그대로 주고받는다. 화면 글꼴 IBM Plex Sans KR([SIL OFL 1.1](crates/app/web/fonts/LICENSE.txt))을 실행 파일에 넣어 파일이 약 1.2 MiB 커졌다.
- 0.8.0 은 화면(요청 개요 · 내 활동 범위 · 주고받은 메시지 접힘 · 내 응답 에이전트 · 메뉴 아이콘 · 연필 · 들여쓰기)과 CLI 도움말 `coworkAgent /?` 를 더했다 — 통신 · DB 형식은 0.7.0 과 같아 섞어 써도 그대로 주고받는다. 0.7.0 이하 상대가 요청 상태를 바꿔도 내 활동에 뜨는 것은 이 PC 가 0.8.0 이면 된다.
- 1.0.0 은 요청 보드 · 사이드바 재배치(에이전트 › 등록된 에이전트 · 에이전트 대화) · 대화 나가기 · 삭제 · 그룹 = 대화만 · 바뀐 범위만 다시 읽기를 더하고, 웹 화면의 편집 모드(내 메시지 고치기 · 지우기)를 뺐다.
  처음 실행 때 DB 를 스키마 21 로 올린다 — 올리기 전 사본(`coworkAgent.db.v20.bak`)을 남기고, 0.8.0 이하는 올린 DB 를 열지 않는다(되돌릴 때는 사본으로). 그룹에 넣어 둔 상대는 그때의 그 상대 대화를 하나씩 넣은 것으로 바뀐다(뒤에 생기는 대화는 들어오지 않는다).
  나가기 알림은 상대도 1.0.0 이상일 때 간다 — 이전 버전 상대가 그 대화로 보내면 거절 사유("상대가 대화를 나갔습니다")로 안다. 그 밖의 기능은 0.8.0 과 그대로 주고받는다.
- 1.0.1 은 요청 보드를 고쳤다 — 카드 손잡이(⠿)로 끌어 놓고(브라우저 끌기 확장이 반응하지 않는다), 놓은 열로 카드가 옮겨진다. 받은 요청 상태는 네 상태 사이 어디로든(되돌리기 포함), 요청 화면의 "메모" 는 "피드백". 통신 · DB 형식은 1.0.0 과 같다.
- 1.1.0 은 세션 생성(글 없이 대화만) · 기록 삭제 › · 나가기 = 목록에서 삭제 · 사이드바 손잡이 끌기 · 타일 크기 · 기본 라이트 · 받은 요청 알림 묶음 · 효과음을 더했다.
  **"기록 삭제 › 모든 사용자 글 삭제"** 는 상대 PC 도 1.1.0 이상이어야 한다 — 1.0.1 이하 상대면 "상대 앱이 이 기능을 모릅니다" 로 거절되고 아무것도 지우지 않는다("내 글만 삭제" 는 된다). 처음 실행 때 DB 를 스키마 23 으로 올린다 — 올리기 전 사본(`coworkAgent.db.v21.bak`)을 남기고, 1.0.1 이하는 올린 DB 를 열지 않는다(되돌릴 때는 사본으로).
- 1.1.0 은 주고받은 메시지 "기간" · 요청 archive(이 PC 에만 — 상대 PC 의 요청 · 상태는 그대로) · 받은 요청을 "대기" 로 되돌리기(고침) · 시작 때 DB 빈 공간 정리를 더한다.
- macOS 실행 파일은 자동 시험(cargo test)까지만 확인한 사전 배포다 — 실사용 확인 · 코드 서명은 아직이다(서명 없음 — 처음 한 번 Gatekeeper 확인이 필요하다, 사용자 가이드 §2).
- 에이전트는 읽기 전용으로만 실행된다 — 파일 수정 · 삭제, 명령 실행 요청에는 할 수 없는 이유를 답한다.
- 질문과 에이전트가 읽은 파일 내용은 답하는 PC 의 Claude 모델 서비스(사내망 밖)로 간다. **비밀이 든 폴더는 에이전트로 등록하지 않는다.**
- **사내망 전용 도구**다. 수신 포트(TCP 47100)를 인터넷에 열지 않는다.
- 초대 메시지가 새면 그 5분 안에 다른 PC 가 연결될 수 있다 — 모르는 연결은 연결 목록에서 바로 "삭제" 한다.
